## Grading

1. **Helper projection width (H_proj_3f, H_proj_c). Floor (d) on the predicate the fix ADDED. L2.**
   - This is the class's second consecutive pass: 0xff in repair 2, now 0x3f and C. The chain rule's closure was applied to the bits the rows already happened to drive, not to the operand's full width.
   - The contract explicitly CLAIMS "WIDENING it, e.g. `& 0xff`".
   - **Guest-visible:** with `& 0x3f`, every SPSR carrying T is declined, so a `subs pc,lr,#4` return to Thumb code stays in IRQ/SVC mode. That is any interrupt taken in Thumb state.
2. **Decline flag provenance (7 mutants). L2 + L4.**
   - The contract's sole carrier sentence reads "the declined SPSR has N Z I F SET while the CPSR it replaces has them CLEAR". It is **false for N and Z**: run_fixed.out R2 is `c00000d1`, and the replaced CPSR is `c0000011`.
   - The PRETABLE section 3 only ever claimed I/F, and that part is correct. The probe header's CONTRACT added N and Z.
3. **Enclosing predicates, cell 2 (D_dpi_pccmpS, C_pop_retflagS). L2 by the JOINT CELLS clause. This one needs a ruling.**
   - DPI: the guarded body itself distinguishes `#ifdef A__S` (the restore) from `#ifndef A__S` (old_pc). So {Rd==PC, Rd!=PC} x {S, non-S} = 4 cells. `encl` holds 3 of them; (S, Rd!=PC) is missing.
   - arm_pop: return_flag = s_bit && pc-in-list, and the enclosing function tests both. `encl` holds (non-S, pc) only; (S, no-pc) is missing.
   - This is `#499`'s shape again: encl was rowed exactly where the `if (1)` mutants struck.
   - Guest consequence: `ldmia sp,{r0-r14}^`, the context-switch idiom, would restore the SPSR.

**(e)-grade, owed disclosure or a cheap row:**
- **O_dpi_movonly.** The opcode does not flow into anything the repair reads, so by the 2026-09-09 label clause it is (e). But `subs pc,lr,#4` is THE IRQ-return idiom, and no row drives a DPI restore through any opcode except MOV.
- **M_msr_clr0f_nonsvc.** A label x width joint. The msr_imm repair does not read the label.
- **M_msr_clr3f.** The T bit at the msr decline. NOT CLAIMED names T only on restore.

## Something else

- **The third pass on the same two classes.** The closure enumerated from the values the rows DRIVE, not from the BITS of the operand and lvalues the repair reads and writes. The rule that ends this chain is per-bit:
  - every bit of the helper operand set in an accept, on each path;
  - every bit of the restored word differing between the old CPSR and the SPSR at each decline cell.

  Closure v2 does exactly that, and it costs 1 extra word per decline plus 2 new rows.
- **`X_msr_latchsvc` is killed by `latch rpt` ALONE (39/40).** One row is the sole carrier of the msr latch x SVC cell.
- **The tbit vehicle depends on the debugger's `print cpsr`.** It reads the raw cpsr, whose top nibble can be stale relative to `flags`. That is why it compares only the low byte. It is not a guest-instruction readback: it is rung 3 with a debugger observation, the same as `print pc` elsewhere.
