def cell_op(A, mode, ks):
    """Repaint, fire one synchronous PUT, then read its whole transfer span."""
    depth8 = ((mode >> 8) & 3) == 3
    paint = ["put w 0x%x, 0x%08x" % (ks, DST_PAINT)]
    if depth8:
        paint += ["put w 0x%x, 0x%08x" % (ks + 4, DST_PAINT_TAIL)]
    return (paint
            + ["a3=0x%x" % DE_MODE_DST,   "t0=0x%x" % mode,
               "a2=0x%x" % DE_PRIM_START, "t1=0x%x" % PRIM_RECT,
               "at=0x%x" % ks,            "v0=0x%x" % SENTINEL]
            + run_ops([OP_SW_T0_A3, OP_SW_T1_A2,

            + ["print v0"])

def printed_seq(t, modes=None):
    raw = re.findall(r"print\s+v0\s*\n\s*(0x[0-9a-f]+)", t)
    if modes is None:
        return ["0x%08x" % (int(v, 16) & 0xffffffff) for v in raw]
    if len(raw) != len(modes):
        return []
    return [("0x%016x" % (int(v, 16) & 0xffffffffffffffff)
             if ((mode >> 8) & 3) == 3
             else "0x%08x" % (int(v, 16) & 0xffffffff))
            for v, mode in zip(raw, modes)]

**Vacuity findings**

- **None of the twelve additions is vacuous under its specified `_ZERO` control.** The target memory observation changes as shown above. Acceptance readbacks and announcement counts remain unchanged under those controls.
- **Announcement count alone would be vacuous for these store-permission mutations.** They preserve the warning behavior. The distinguishing assertion is the destination value.
- **Repainting cannot erase the evidence:** each PUT’s load and `print v0` precede the next operation’s repaint. The repeat session records its priming decline separately.
- **The existing four depth-eight assertions were blind to tail-only corruption.** Under `TAIL8_ZERO`, their former four-byte observations cannot change. After replacements 2–6, their expected `0x1122334455667788` changes to **PREDICTION: `0x1122334400000000`**. The four new depth-eight rows observe that difference too.
- The RGBA controls use depth four, whose packing initializes every transferred byte. At the added origin coordinates, changing depth leaves index and offset zero. This avoids introducing an accepted depth-eight buffer-initialization dependency into the setup.
- These rows do not establish cold-page behavior. Their named mutations change the colour helper’s decision independently of page warmth. No status-register value is used as evidence of refusal.
- For an uninitialized-buffer mutant, paint equality remains possible. That is an oracle limitation, not proof of refusal. **For the exact historical M28/M28r, the files do not settle the kill.**
