### Q2 — option and exact shape

**(d) is a feature** (ITB/ACV via PALcode). Dummy `kentry[]` exists (`cpu_alpha.c:99-103`); the walk TODOs are still TODOs; there is no miss → PAL path. Out of scope.

**(e), in the shared generic, not Alpha-ifdef.** `(c)` is the same stop with a worse predicate.

`DYNTRANS_PC_TO_POINTERS_GENERIC` is `void`. Today it has **one** exit: fall off the end after `:830-833` set `cur_ic_page` / `next_ic`. The new path is a **second** exit: early `return` from the `if (!ok)` arm, **before** `physaddr = paddr`.

Replace `:720-733` with this shape (not a drop-in of `:2002-2034`):

```c
		if (!ok) {
			cached_pc = cpu->pc;
			/* existing fast-table lookup of cached_pc ... */
			if (!ok && cpu->pc != /* the VA we just failed */)
				ok = cpu->translate_v2p(cpu, cpu->pc, &paddr,
				    FLAG_INSTR);
			if (!ok) {
				static int warned; /* per-arch TU; CPU is stopping */
				if (!warned) {
					warned = 1;
					fatal("instruction fetch: no translation"
					    " for pc=0x%016" PRIx64
					    " (once)\n", (uint64_t)cpu->pc);
				}
				about_to_enter_single_step = true;
				cpu->running = 0;
				debugger_reset();
				cpu->cd.DYNTRANS_ARCH.next_ic = &nothing_call;
				/* NO next_ic++; NO ic->f() */
				return;
			}
		}
```

The PC-unchanged test is the Alpha case expressed from the function’s own state: if `translate_v2p` did not move PC, do not retry the same miss (drops the JMP from two walk diagnostics to one). If PC *did* move (MIPS/SH/M88K), keep today’s retry. If the retry still misses (M88K unmapped VBR), **stop**, do not `exit(1)`.

**Why the unimplemented sequence is not copy-paste:**

| unimplemented (`:2023-2034`) | this site |
|---|---|
| Inside an `I` (this instruction *is* the stop) | `pc_to_pointers` is a helper; the next `I` has not run |
| `next_ic = &nothing_call; next_ic++; ic->f()` | `next_ic = &nothing_call;` only. The `++`/`f()` pair is because they consume this `I`. Copying it here leaves `next_ic` **past** `nothing_call`; the caller’s `I` then executes **.data after the static** |
| `cur_ic_page` already the page of the bad opcode | Must **leave `cur_ic_page` alone**. Pointing it at `&nothing_call` makes the epilogue (`:394-400`) compute `low_pc == 0` and **snap `cpu->pc` to the page base** of the faulting VA |

**On the early return:**

- `cpu->pc` — still the faulting VA (JMP/BR already wrote it; `end_of_page` already advanced to the next page base; cold `run_instr` already had it).
- `next_ic` — `&nothing_call`.
- `cur_ic_page` — previous page or NULL.
- `running` — 0.

**What the run loop does next**

1. **Caller = `run_instr` `:190`.** Interrupt check. `:265` `cached_pc = cpu->pc` (faulting VA). `:267` **zeroes `n_translated_instrs` after we returned** — that is the Codex accounting trap; it is the same as unimplemented and is acceptable. Single-step may print `could not read` (`:287-290`) and still `I`. `I` runs `nothing`, which parks `next_ic` on itself. Free-run burns `nothing_call` until `N_SAFE_DYNTRANS_LIMIT`. Epilogue: `low_pc = (&nothing_call - old cur_ic_page) / sizeof(IC)` is almost certainly **not** in `[0, PAGE+1]`, so the `if/else if` chain does **not** rewrite `pc`. `machine_run` skips this CPU next timeslice (`machine.c:708`). `about_to_enter_single_step` opens the debugger.

2. **Caller = `jsr` / `jsr_0` / `br` / `br_return` / `call_pal` / `end_of_page`** (`cpu_alpha_instr.c` `:72`, `:108`, `:149`, `:184`, `:211`, `:757`). Handler returns into the unrolled `I` loop; remaining `I`s spin on `nothing_call`. Same epilogue. JMP/BR have already set `cpu->pc` to the target; that is the value to keep.

3. **Do not** `physaddr = paddr`, do not allocate a TC page, do not `memory_paddr_to_hostaddr` on garbage.

Latch: `(once)` on a function-static is enough **because the CPU stops** (no flood). A new `cpu->cd.alpha` field is an addition `#541` is already making for a **different** `exit(1)` (`memory_alpha.c:75-78`, identity-map kernel VA). Do not share that field; different site, different round.
