**Q4.** What all nine (and the author) appear to have missed, in order of what the packet will support:

1. **literal_offenders has more than one escape.** The `+` concatenation is disclosed (F12). It is not the only one: a string built by `chr(...)` and `+`, by `str.format`, by `%`-formatting, or by an f-string whose literal parts do not individually contain a core (e.g., `f"[{H} {A} {S}]"` with H/A/S as names) is never a single Constant and so is not walked. The check catches partial constants containing a core; it does not catch computed strings.

2. **F14 is unpriced.** "OWED WHEN IT SHIPS" is a permanent deferral as written. A round or date is not named.

3. **The docstring for clause (ii) is misleading.** It says "no exemption entry names" but the code only checks NOPANEL entries (`nop = [e for e in tok if NOPANEL in _note(e)]`). The intent matches the code (NOPANEL-only, because only (ii) is retroactive), but the prose overshoots.

4. **`_CORES[ANNOTATION]` redundancy.** `("PRE-2026-08-16 POLICY", "RUN UNDER THE PRE")` — the actual token contains both, so under `any` either alone catches it. If the goal is to catch fragments, the cores should be the smallest discriminative substrings, not overlapping phrases of the token itself.

5. **literal_offenders' docstring exclusion is narrow.** Module/FunctionDef/AsyncFunctionDef/ClassDef only. A module whose first statement is not a docstring (e.g., `from __future__ import annotations; """..."""`) leaves the second-statement docstring un-excluded, and a `__doc__ = "..."` re-assignment is an Assign whose Constant value is not in `docs`.
