### (b) What both the reviewer and the draft missed in those files

1. **`src/devices/dev_pvr.c:591–592` zero-height calculation**:
   ```c
   if (d->line_double)
       d->ysize /= 2;
   ```
   At `src/devices/dev_pvr.c:573`, `d->ysize` is derived from `DIWSIZE_LPF` and incremented by 1 (`:577`). If `LPF == 0`, `d->ysize` is 1. If `line_double` is non-zero, integer division `1 / 2` sets `d->ysize = 0`. At `src/devices/dev_pvr.c:2316–2317`, the overlap check evaluates `bytes_per_line * d->ysize`, which becomes 0. For any crossing span with `high >= 0` and `low < 0`, this condition passes even when `d->xsize != 0`.
2. **`src/devices/dev_pvr.c:2461–2462` potential negative host framebuffer offset**:
   ```c
   fb_ofs = (d->fb_update_y1 + PVR_MARGIN) * d->fb->bytes_per_line;
   fb_ofs += (d->fb_update_x1 + PVR_MARGIN) * d->fb->bit_depth / 8;
   ```
   If unsigned division in `pvr_extend_update_region` produces a large 64-bit quotient whose lower 32 bits have bit 31 set, truncation to `int new_y1` produces a large negative integer. If `d->fb_update_y1 < -PVR_MARGIN` (where `PVR_MARGIN == 5`), `fb_ofs` becomes negative, leading to an out-of-bounds heap write into the host framebuffer buffer `fb[fo]` at `:2479–2482`, `:2502–2505`, `:2525–2527`, or `:2544–2547`.
3. **`src/devices/dev_pvr.c:1678` unlatched guest-drivable diagnostic**:
   `fatal("[ pvr: huh? read from STARTRENDER ]\n");`
   An unlatched `fatal()` occurs on any guest read from `PVRREG_STARTRENDER`, creating an unthrottled host log flood (floodclass, LOW).
4. **`src/devices/dev_pvr.c:322` unlatched guest-drivable DMA interrupt diagnostic**:
   `fatal("TODO: pvr sh4 dmac interrupt!\n");`
   An unlatched `fatal()` fires on every completed TA DMA transfer when `CHCR_IE` is enabled (floodclass, LOW).
5. **`src/devices/dev_lca.c:235–239` type-0 configuration cycle misrouting**:
   ```c
   for (dev=0; dev<21; dev++)
       if (tag & (0x800U << dev))
           break;
   if (dev >= 21) {
       dev = 0;
   }
   ```
   In `dev_lca_pci_conf_access`, if a type-0 configuration access has no IDSEL bit asserted in `tag` (bits 11..31 all zero), `dev` reaches 21, and the code substitutes `dev = 0`. Instead of returning master abort / all-ones, it quietly redirects the access to device 0 on bus 0 (`i82378zb`).
6. **`src/cpus/cpu_sh.c:373` vs `:592` systematic arbitration priority divergence**:
   In `sh_cpu_interrupt_assert` (`:592`), an incoming interrupt replaces `int_to_assert` only if `prio > cpu->cd.sh.int_level` (strictly greater), retaining arrival order for equal priorities. In `sh_recalc_int_to_assert` (`:370–375`), the table scan evaluates `index=0` ascending, selecting the lowest INTEVT code on equal priorities. Thus, equal-priority arbitration diverges systematically across ALL shared priority levels depending on whether an assertion occurs directly or via a register write rescan.
7. **`src/cpus/cpu_sh.c:911` unlatched diagnostic under BL**:
   `fatal("[ sh_exception(): BL bit already set. ]\n");`
   Fires on every guest exception occurring while SR.BL is set, creating an unlatched host log flood (floodclass, LOW).
8. **`src/cpus/cpu_alpha_palcode.c:440–443` guest-drivable CPU halt**:
   `fatal("[ Alpha PALcode: PAL_OSF1_wrent: attempt to write to non-implemented selector %i ]\n", (int)a1);`
   `cpu->running = 0;`
   A guest calling `PAL_OSF1_wrent` with `a1 >= N_ALPHA_KENTRY` logs `fatal()` and permanently stops the CPU (`cpu->running = 0`).
9. **`src/cpus/cpu_alpha_palcode.c:281,283` PCB loads omit `PHYSICAL`**:
   `load_32bit_word(cpu, cpu->cd.alpha.ctx + 24)` and `load_32bit_word(cpu, cpu->cd.alpha.ctx + 28)` for `new_cpc` and `new_asn` pass no `PHYSICAL` flag, sharing the `alphapcbbvirt` virtual translation defect.
