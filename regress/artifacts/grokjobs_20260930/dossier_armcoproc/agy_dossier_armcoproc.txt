### (a) Dossier's Chosen Disposition Member & Machine Machinery

#### 1. Evaluation of Member 3 (State-Preserving Containment / Latched Decline)
The dossier's choice of **Member 3 (Decline with CPU-local warn-once latch)** as the interim containment disposition is correct:
- **State Integrity**:
  - For Site 264 (PID): Simply deleting the exit (Member 1) or accepting the write (Member 4) commits `cpu->cd.arm.pid = cpu->cd.arm.r[rd];`. Because [`memory_arm.c:118–131`](file:///C:/DocumentNoSnc/cc/GXEMUL/GXEMUL-SEC/src/cpus/memory_arm.c#L118-L131) lacks FCSE translation logic, subsequent MMU translations would run against un-remapped virtual addresses while advertising a non-zero PID to readback. Refusing the write before assignment prevents entering an inconsistent state.
  - For Site 322 (ISTEER): Writing `i80321_isteer` changes state that [`dev_i80321.c:83–94`](file:///C:/DocumentNoSnc/cc/GXEMUL/GXEMUL-SEC/src/devices/dev_i80321.c#L83-L94) cannot honor, since FIQ interrupts are unhandled ([`src/cpus/cpu_arm.c:209`](file:///C:/DocumentNoSnc/cc/GXEMUL/GXEMUL-SEC/src/cpus/cpu_arm.c#L209)).
