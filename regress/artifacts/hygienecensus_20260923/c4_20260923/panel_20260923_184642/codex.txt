   9 a separate match, so neither can happen here.  (A probe in a subdirectory judged by a same-named top-level file was
  10 the third defect that pass measured; the GATE fixed that, by passing paths relative to regress/.)
  11 
  12 Statement boundaries are KEPT.  The first version dropped NEWLINE tokens with the other layout tokens, so a method
  13 REFERENCE on one statement and a parenthesised string on the next -- `x = buf.rstrip().endswith` / `("GXemul>")` --
  14 read as one whole-buffer call, and a probe whose readiness test had been turned into that passed every row (measured by
  15 the census closing pass, controls_c2/t_nljoin).  NL, the newline INSIDE brackets, is still layout.  And a call is
  16 counted only where the name follows a "." -- a function DEFINITION under that name calls nothing, and the first
  17 version credited one (codex, the same pass).  Tokens are not a parse: a class PATTERN of the same shape in a `match`
  18 statement (`case K.<name>(...)`) is still counted, and a call through an alias with no "." before the name is not
  19 (the F3 pass, codex; the second fails closed -- the probe is listed promptless).
  20 
  21 The CLOSED-WORLD counts (a bare prompt-suffix test, an unrecognised spelling of the ends-with call) are NOT done here
  22 and must not be: they count TEXT on code lines, in the gate itself, so a comment or a string that spells the method
  23 is counted -- the safe direction.  They see only the literal spelling with no space before the parenthesis (a space
  24 passes them: hygienecensusholes e9).  THIS FILE IS SCANNED BY THOSE COUNTS TOO (it is a top-level regress/*.py),
  25 which is why the method's name never appears here followed directly by an opening parenthesis -- not in code, not in
  26 this docstring.
  27 
  28 Usage (paths are read one per line from stdin, relative to the directory given):
  29     census_tokens.py promptless DIR   print each path with no method call of the ends-with method: the OP token ".",
  30                                       a NAME token spelled ENDS_WITH, the OP token "(", in one statement.  A file that
  31                                       cannot be read or tokenized is PRINTED (listed promptless: it cannot be read, so it
  32                                       is not trusted).  Tokens are not a parse: a file that tokenizes but would not
  33                                       compile is graded like any other.
  34     census_tokens.py whole DIR        print "path:N" for each path with N > 0 code-level whole-buffer sites: a NAME
  35                                       whose last three letters are "buf", then ".", "rstrip", "(", ")", ".", ENDS_WITH,
  36                                       "(", a STRING whose value is exactly "GXemul>", ")", in one statement.  Counted
  37                                       per OCCURRENCE, either quote, any spacing between the tokens.  An unreadable file
  38                                       prints NOTHING here (it has no count); the promptless mode is what names it.
  39 Exit status 2 on a usage error; otherwise 0 -- an unreadable path is an output (promptless) or a missing count (whole),
  40 never an exception.  On Python 3.12 and later an f-string's replacement fields are tokenized as code, so a call inside
  41 one counts; on earlier versions it is one STRING token and does not (no probe relies on either).
  42 """
  43 import ast, io, os, sys, tokenize
  44 
  45 ENDS_WITH = "ends" + "with"          # spelled in two halves: see the docstring's CLOSED-WORLD paragraph
  46 SKIP = (tokenize.NL, tokenize.INDENT, tokenize.DEDENT, tokenize.COMMENT, tokenize.ENCODING)   # NEWLINE is KEPT
  47 
  48 
  49 def code_tokens(path):
  50     src = io.open(path, encoding="utf-8", errors="strict").read()
  51     return [t for t in tokenize.generate_tokens(io.StringIO(src).readline) if t.type not in SKIP]
  52 
  53 
  54 def has_ends_with_call(toks):
  55     return any(d.type == tokenize.OP and d.string == "." and a.type == tokenize.NAME and a.string == ENDS_WITH
  56                and b.type == tokenize.OP and b.string == "("
  57                for d, a, b in zip(toks, toks[1:], toks[2:]))
  58 
  59 
  60 def is_prompt_string(t):
  61     if t.type != tokenize.STRING:
  62         return False
  63     try:
  64         return ast.literal_eval(t.string) == "GXemul>"
  65     except (ValueError, SyntaxError):
  66         return False
  67 
  68 
  69 SHAPE = [(tokenize.OP, "."), (tokenize.NAME, "rstrip"), (tokenize.OP, "("), (tokenize.OP, ")"), (tokenize.OP, "."),
  70          (tokenize.NAME, ENDS_WITH), (tokenize.OP, "("), (tokenize.STRING, None), (tokenize.OP, ")")]
  71 
  72 
  73 def whole_sites(toks):
  74     n = 0
  75     for i in range(len(toks) - len(SHAPE)):
  76         head = toks[i]
  77         if head.type != tokenize.NAME or head.string[-3:] != "buf":
  78             continue
  79         rest = toks[i + 1:i + 1 + len(SHAPE)]
  80         if all(t.type == kind and (text is None or t.string == text) for (kind, text), t in zip(SHAPE, rest)) \
  81                 and is_prompt_string(rest[7]):
  82             n += 1
  83     return n
  84 
  85 
  86 def main(argv):
  87     if len(argv) != 3 or argv[1] not in ("promptless", "whole"):
  88         sys.stderr.write(__doc__)
  89         return 2
  90     mode, base = argv[1], argv[2]
  91     for line in sys.stdin.read().split("\n"):
  92         rel = line.strip("\r")
  93         if not rel:
  94             continue
  95         try:
  96             toks = code_tokens(os.path.join(base, rel))
  97         except (OSError, ValueError, UnicodeDecodeError, tokenize.TokenError, SyntaxError, IndentationError):
  98             if mode == "promptless":
  99                 print(rel)
 100             continue
 101         if mode == "promptless":
 102             if not has_ends_with_call(toks):
 103                 print(rel)
 104         else:
 105             n = whole_sites(toks)
 106             if n:
 107                 print("%s:%d" % (rel, n))
 108     return 0
 109 
 110 
 111 if __name__ == "__main__":
 112     sys.exit(main(sys.argv))
