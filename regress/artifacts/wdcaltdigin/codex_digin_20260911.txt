5. **For (c), the positive oracle must assert the specified encoding, not merely that the result changes.**

   The existing invariance witness establishes the missing dependence. Its inverse—“head 0 and head 15 return different values”—would be a weak correctness test.

   Once the specification supplies the masks and values, exercise the guest register interface for **both drive selections and all 16 head nibbles**, in a specified controller state, and require:

   ```text
   (actual & specified_mask) == (expected[drive][head] & specified_mask)
   ```

   The expected table should come independently from the specification, rather than calling or duplicating the implementation’s encoder. Bits whose values are unspecified must be excluded from the hardware oracle; any chosen deterministic emulator policy for them needs a separate assertion.

   Conditionally, if the specification confirms four active-low head bits, the extracted raw field must equal `head ^ 0x0f`. If it confirms separate active-low drive-select lines, the selected line must be zero and the unselected line one. Those are **conditional oracle rules**, not a sourced layout from these files.

   The coverage limits matter:

   | Test | Wrong implementations that could still pass |
   |---|---|
   | Only require different values at heads 0 and 15 | Wrong polarity, wrong bit positions, a single toggling bit, or a response that alternates on reads |
   | Require exact specified values at heads 0 and 15 | Permuted head-bit significance, incorrect intermediate heads, and an ignored drive selector if only one drive is tested |
   | Exhaustively check both drives and every head in one state | Correct static encoding with stale updates after other operations, read side effects, mistakes in other modes or device-presence states, or incorrect machine routing bypassed by direct callback tests |

   Repeat reads and vary the selection order to catch read-count or stale-state behavior. Check selection fields while varying unrelated status conditions, and separately verify defined non-selection fields in the states their specification requires.

   Preserve offset-0 behavior as a separate regression obligation: its status value and interrupt behavior must remain correct. Ordinary STATUS explicitly acknowledges the interrupt at lines 1938–1939; the alternate handler does not. [dev_wdc.c:1932](C:/DocumentNoSnc/CC/GXEMUL/GXEMUL-SEC/src/devices/dev_wdc.c:1932)

   For an FDC-ownership disposition, the positive oracle would instead establish that the address reaches the intended owner and returns that owner’s specified response. Head-dependent ATA readback would then be the wrong acceptance criterion.
