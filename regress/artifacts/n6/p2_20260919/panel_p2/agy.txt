  - **READ**: [`regress/fbpending_drain_probe.py:404-425`](file:///C:/DocumentNoSnc/CC/GXEMUL/GXEMUL-SEC/regress/fbpending_drain_probe.py#L404-L425), [`regress/fbpending_witness.py:344-368`](file:///C:/DocumentNoSnc/CC/GXEMUL/GXEMUL-SEC/regress/fbpending_witness.py#L344-L368).
  - **REASONED**: When the pty master closes, the kernel sends SIGHUP to the slave session leader. The child cannot survive master close unless held in an uninterruptible kernel D-state (which user-space emulation does not trigger).
  - `survived()` (`status == "SURVIVED" and exit == 0`) does not alter any healthy arm's verdict, since healthy arms process `"quit\n"` and exit 0.
  - In `fbpending_witness.py`, unpacking `**end` into `run_witness` adds `exit` and `signal` without deleting or altering any existing keys (`status`, `samples`, `regs`, `badis`, `catchup`). All existing consumers are unaffected.
* **(d) Arm E Register Alignment & Controls**:
  - **READ**: [`regress/footbridge_sites_probe.py:507-521, 580-585`](file:///C:/DocumentNoSnc/CC/GXEMUL/GXEMUL-SEC/regress/footbridge_sites_probe.py#L507-L585).
  - Register correspondence: E0 -> r7; E1 -> r1; E2 -> r2; E3 -> r9; E6 -> fp (r11); E5 -> ip (r12).
  - No register is clobbered before dump: r5 (EC1) and r6 (EA1) from BODY remain pristine; r8 (P) is written to Set and Clear; r9 is overwritten by E3 byte read only after Set <- Q completes.
  - EC1 (RAM readback) and EA1 (VENDOR_ID 0x1011) are the correct positive controls; without them, an absent/unmapped device would yield 0 at E0 and falsely pass.
