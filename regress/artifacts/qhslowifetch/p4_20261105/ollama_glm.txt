## 3. F6 — right

Re-derived from the quoted prologue, ENUMERATED: the page mask is (N−1)<<2 — with N=1024, 0xFFC, clearing bits 2..11 (slot-index bits) and **leaving bits 0-1**. pc=0x103: line 1 → addr=0x003; line 2 restores the slot bits → addr=0x103; line 3: cpu->pc = 0x103 (bits 0-1 survive); line 4: addr = 0x100. So cpu->pc is assigned the pre-alignment value and only addr is aligned: a debugger-set unaligned pc reaches the failure block with cpu->pc ≠ addr, arm (b) fires. READ+REASONED: the ruling's realignment premise fails, exactly as stated. Filing rather than rowing is right: an unaligned pc is not a guest state (REASONED: PowerPC branch targets are word-aligned — immediates are scaled by 4, indirect targets' low bits ignored), so a row would demand a cell outside the guest-reachable bound; D11/V2 green is consistent; the block comment's "reached on no measured session" stays true.
