## Q2 — the clause-(d) enumeration

Domain first, enumerated [READ from the inlined predicate]: the specific-EOI set is {0x21–0x27, 0x60–0x67, 0xe0–0xe7} = 23 opcodes; n = idata&7 is 1–7 for the first range, 0–7 for the others; **line 0 is reachable only via 0x60/0xe0** (0x20 is captured by the non-specific arm).

**Variant `if (d->ier & bit)`** (clear only when masked): **no current or planned row catches it.** The symptom rows run unmasked (IMR is 0x10 only after the masked scenario's OCW1 write), so the clear never fires and `eoi irr4`/`eoi x8` read the fix values — green. The `masked irr4` row cannot catch it either, derivable from the packet itself: under HEAD the clear is *unconditional*, so if the masked scenario contained [EOI-while-masked + sub-tick IRR read], HEAD's recorded got would be 0x00; the recorded got is 0x01 — no such sequence exists, and any slower read is laundered by the tick re-assert. The planned rows (B/8253/pic2) all EOI unmasked. **Row that stays green: `eoi irr4` (and `eoi x8`, `masked irr4`). Required new row: [OCW1 0x10 → EOI 0x64 → read IRR4 within 2 instructions → want 1].**

**Variant `if (n != 4)`**: green on `eoi irr4`/`eoi x8` by construction; no other row in the 19 evidences an observable n≠4 specific EOI. Of the planned rows, the **pic2 line-12 row does NOT catch it** — line 12's slave EOI is 0x60|(12&7) = 0x64, n=4 again [REASONED; and 0x60|12 = 0x6c falls past every arm to the fatal else and halts the emulator]. The planned **8253 row (n=0) reds — if reachable**: clear fires, IRR0 reads 0 against fix-want 1. **Row that stays green: `eoi irr4`. Required: one unconditional n≠4 EOI-with-held-level row** (8253, or RTC on line 8 → pic2 n=0).

**Variant `if (d->isr & bit)`**: **nothing can catch it, ever, under (A)** — by enumeration from Q1(ii) no code path sets any ISR bit, so the condition is identically false and the variant is observationally equivalent to the fix. All 19 + planned rows stay green. This is not a detector weakness; the (d) table must record it as *unfalsifiable under (A)* — a claimed red here would be a false instrument. It becomes falsifiable only under (B), and then only via a row [poll → EOI 0x64 → read IRR4] — which is **not** among the named planned rows (`poll sets isr`, `eoi clears isr` read ISR, not post-EOI IRR).
