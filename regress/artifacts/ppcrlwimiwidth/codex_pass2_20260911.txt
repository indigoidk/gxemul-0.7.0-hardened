2. **When `mb` equals the stopping position, the loop sets all 64 bits.**

   Let `E = (64-sh)&63`. Starting with `m == E`:

   ```text
   set E;       advance to E+1 modulo 64; continue
   set E+1;     advance again;            continue
   ...
   set E-1;     advance to E;             stop
   ```

   The condition is tested after advancing, so equality at entry does not cause an immediate exit.

   For `SH=1, MB=63`, the architectural endpoint is 62:

   ```text
   set 63 → set 0 → ... → set 62 → advance to 63 → stop
   ```

   That is 64 iterations and the correct full wrapping mask.

   `SH=0, MB=0` also takes 64 iterations, producing `MASK(0,63)`; that particular full mask is nonwrapping. A genuine one-bit case is `SH=63, MB=0`: set bit 0, advance to 1, stop.

   - `~mask` has ones throughout the high word, so `ra &= ~mask` preserves that word.
