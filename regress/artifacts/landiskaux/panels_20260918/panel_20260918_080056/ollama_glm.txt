**Q1 — literal `+ 0x2c`.** All three arms and the default are byte offsets/absolutes; none multiplies by `addr_mult` [READ]. **Q4 — delta real; right member is the case with the literal.** The delta (12 genuine stores, including a discarded ATA soft reset, to an address where the wdc provides no listener) is real on packet evidence. Members: (1) the one case, literal offset — smallest, idiom-consistent, licensed. (3) HPCMIPS-style absolute — per F1 that pattern is demonstrated dead code here, and it breaks if a second instance ever appears. Reject. (4) Change the default — touches every machine not in the switch; unlicensed by this delta. Reject. (5) Do nothing — discards a soft reset; unlicensed.

**Q5 — smallest breaking edits, and the detector they force.** Against a boot-green detector: `0x16` → `0x17` (one character) lands altstatus at 0x140002e, the stores are still swallowed, boot unchanged, no diagnostic.
