  TAILHALT   `internal error` printed and the machine stopped (the naive fix's shape)
  STOP       the machine stopped for another reason (e.g. a wrong vector base landed in zeros)
  BADREGS    the entry breakpoint fired but a shadow-register/PSR/destination assert failed, or
             (bad=level) the transcript carried an `exception <CLASS>' line: the class printed at ERROR
             level, which the fork's default WARNING verbosity shows and INFO does not (kills M_LEVEL)
  (rows resid50 and sfu1h EXPECT HALT: the fallback stopping the machine is the correct answer there)
  DELIVER    entry breakpoint fired, machine running, and every assert holds:
             pc == entry, SXIP == fault_pc|V, SNIP, SFIP, PSR == 0x8000000b (SFRZ|IND|SFD1|MODE),
             EPSR == the pre-fault PSR (0x80000002 supervisor rows; 0x00000002 user-mode rows),
             r2 unchanged (0xdeadbeef)
  NOSTART    the liveness marker never ran
Controls print DONE (r2 == the expected quotient, machine running) or a failure word.

Output: one `M88KEXC_ROW=<name> RESULT=<word> ...` line per row, `M88KEXC_RESULT=<delivered>/<fault rows>`,
`M88KEXC_SELFTEST=OK|FAIL`, `M88KEXC_DONE`.  Set M88KEXC_VERBOSE=1 for transcripts.

CONTRACT (clause e): catches a class returned to the fallback (HALT) by either route (instruction rows
and the *tb trap rows); a class reaching the tail default (TAILHALT); a wrong vector SCALING (M_VEC4,
M_VEC7: STOP) and a DROPPED vector base (vbrtb: STOP); a stale SXIP/SNIP/SFIP; a wrong PSR, including a
cleared carry (ovfc); a dropped IND (indclr); the debugmsg LEVEL regression to ERROR/WARNING (bad=level on any
delivered row: those print at the post-startup WARNING floor, INFO and DEBUG do not -- so exact INFO is NOT pinned,
only 'not ERROR/WARNING' -- M_LEVEL; codex, pass 3); a skipped EPSR save; a skipped supervisor switch (the user-mode rows: EPSR MODE
clear vs PSR MODE set); a wrong return address; the delay-slot else-arm's SFIP source (dslot, +16
geometry); a trap re-routed to ERROR while frozen (trapfrozen); a written destination.  Does NOT catch:
fcr2/fcr4/fcr5; scoreboard (SSBR) bits; DMT contents; the post-delivery
`cpu->delay_slot' write on the NON-delay path (M_DELAYALWAYS: needs a second UNFROZEN exception -- filed);
vectors 0..3's tail arms (no row: M_TAILOFF -- filed); vectors 11..113 and 116..127 (fallback halts by
design); SFU1 (114/115, row m88kexcsfu1); `implemented = is_trap' on BOUNDS/ERROR (EQUIVALENT today: no
instruction raises 7 or 10 -- becomes live when tbnd lands, row m88ktbnd).
"""

EXPECT_R2 = {"live": 6, "attrib": 1}
VBR_OF = {"vbrtb": VBR_TEST}                     # rows that relocate the vector table; every other row runs with VBR == 0
#  NEGATIVE CONTROLS: rows whose CORRECT result is the fallback HALT.  They pin the boundary the diff keeps on purpose --
#  vectors 11..113/116..127 and SFU1 (114/115) still stop the machine -- and separate the shipped D1 form from the rejected
#  D4 (tail-default-delivers) and from delivering SFU1 (row m88kexcsfu1).  A mutant that delivers them turns these rows RED.
EXPECT_RESULT = {"resid50": "HALT", "sfu1h": "HALT"}
PSR_WANT = {"ovfc": 0x9000000b}                  # MODE | C | SFD1 | IND | SFRZ: carry PRESERVED through the exception path
#  indclr wants the default PSR_EXC (0x8000000b): IND was CLEAR before the fault and must be SET by the exception path;
#  EPSR keeps the pre-fault 0x80000000.  A write that drops `| M88K_PSR_IND' leaves 0x80000009 -> bad=psr.
EXPECT_VECTOR = {"resid50": 0x032, "sfu1h": 0x072}   # the vector the fallback diagnostic must NAME for an expected-HALT row

class Sess:
    def __init__(self):
        stub = "/tmp/gx_m88k_exc_%d.bin" % os.getpid()
        with open(stub, "wb") as f:
            f.write(struct.pack(">I", 0xf4005800))          # or r0,r0,r0 so the machine constructs
        self.pid, self.fd = pty.fork()
        if self.pid == 0:
            os.execvp(BIN, [BIN, "-V", "-E", "testm88k", "-M", "64", "0x10000:%s" % stub])
            os._exit(127)
        self.buf = ""
    def rd(self, t=0.4):
        r, _, _ = select.select([self.fd], [], [], t)
        if self.fd not in r:
            return True
        try:
            d = os.read(self.fd, 65536)
        except OSError:
            return False
        if not d:
            return False
        self.buf += d.decode("latin1", "replace")
        return True
    def wait_prompt(self, mark, timeout=30):
        t = time.time()
        while time.time() - t < timeout:
            if not self.rd():
                return False
            if len(self.buf) > mark and self.buf[mark:].rstrip().endswith("GXemul>"):
                return True
        return False
    def send(self, sx, timeout=30):
        mark = len(self.buf)
        b = (sx + "\n").encode("latin1"); n = 0
        while n < len(b):
            n += os.write(self.fd, b[n:])
        self.wait_prompt(mark, timeout)
        return mark
    def cr(self, name):
        m = self.send("reg 0,0")
        mm = re.search(r"(?<![A-Z])%s=0x([0-9a-f]{8})" % name, self.buf[m:])
        return int(mm.group(1), 16) if mm else None
    def gpr(self, n):
        m = self.send("reg")
        mm = re.search(r"r%-2d\s*=\s*0x([0-9a-f]{8})" % n, self.buf[m:])
        return int(mm.group(1), 16) if mm else None
    def pc(self):
        m = self.send("reg")
        mm = re.search(r"pc\s*=\s*0x([0-9a-f]{8})", self.buf[m:])
        return int(mm.group(1), 16) if mm else None
    def close(self):
        try:
            os.write(self.fd, b"quit\n"); time.sleep(0.3); os.kill(self.pid, 9); os.waitpid(self.pid, 0)
        except Exception:
            pass

def fmt(v):
    return ("0x%08x" % v) if isinstance(v, int) else str(v)

def run_row(name, prog, regs, vector, fault_pc, epsr_exp, handler, grace=6.0):
    s = Sess()
    if not s.wait_prompt(0, 60):
        s.close(); return dict(result="NOBOOT")
    vbr = VBR_OF.get(name, 0)
    entry = (vbr + 8 * vector) if vector is not None else None
    words = [MARK] + prog + [SELF]
    for i, w in enumerate(words):
        s.send("put w 0x%x, 0x%08x" % (CODE + 4 * i, w))
    for base in sorted({0, vbr}):                       # every entry spins unless a handler is planted (both tables if relocated)
        for v in VECTORS:
            s.send("put w 0x%x, 0x%08x" % (base + 8 * v, SELF))
    if entry is not None:
        s.send("put w 0x%x, 0x%08x" % (entry, SELF))
    if handler:
        for i, w in enumerate(handler):
            s.send("put w 0x%x, 0x%08x" % (8 * V_DIV0 + 4 * i, w))
        s.send("put w 0x%x, 0x%08x" % (8 * V_DIV0 + 4 * len(handler), SELF))
    s.send("put w 0x%x, 0x%08x" % (DATA, 0x0badf00d))
    for r, v in regs.items():
        s.send("%s=0x%x" % (r, v))
    s.send("r10=0x12345678"); s.send("r2=0xdeadbeef")
    if vector is not None:
        s.send("breakpoint add 0x%x" % entry)
    s.send("pc=0x%x" % CODE)
    mark = len(s.buf)
    os.write(s.fd, b"continue\n")
    t = time.time()
    while time.time() - t < grace:
        s.rd(0.3)
        if s.buf[mark:].rstrip().endswith("GXemul>"):
            break
    if not s.buf[mark:].rstrip().endswith("GXemul>"):
        os.write(s.fd, b"\x03"); s.wait_prompt(len(s.buf), 15)
    tr = s.buf[mark:]
    #  HALT is the fallback's diagnostic AND the machine-stopped observation (codex, pass 3: a mutant that keeps the
    #  message and drops the stop would otherwise classify as HALT); an expected-HALT row must also see ITS vector named.
    diag = re.search(r"unimplemented[^\r\n]*vector=0x([0-9a-f]+)", tr)
    halted = diag is not None and ("machines stopped" in tr or "stopped" in tr)
    if halted and name in EXPECT_VECTOR and int(diag.group(1), 16) != EXPECT_VECTOR[name]:
        halted = False                              # halted on some OTHER vector: not the row's answer
    #  LEVEL channel (Fable review seat, pass 2): main.c lowers every subsystem to WARNING after startup, so a
    #  free-running `continue' prints an ERROR-level `[ exception <CLASS>: ]' line and stays silent at INFO.  A
    #  delivered row that carries the line has the pre-fix level (M_LEVEL) -- #261's opt-in break-on-ERROR would
    #  then stop the emulator into the debugger on a user process's divide by zero.
    levelmsg = re.search(r"exception (MISALIGNED_ACCESS|UNIMPLEMENTED_OPCODE|PRIVILEGE_VIOLATION|"
                         r"BOUNDS_CHECK_VIOLATION|ILLEGAL_INTEGER_DIVIDE|INTEGER_OVERFLOW|ERROR)", tr) is not None
    tailhalt = "internal error" in tr
    stopped = "machines stopped" in tr
    pc = s.pc(); r2 = s.gpr(2); r9 = s.gpr(9)
    sxip, snip, sfip, psr, epsr = s.cr("SXIP"), s.cr("SNIP"), s.cr("SFIP"), s.cr("PSR"), s.cr("EPSR")
    s.close()
    started = (r9 == 0x12345678)
    res = dict(pc=pc, sxip=sxip, snip=snip, sfip=sfip, psr=psr, epsr=epsr, r2=r2, transcript=tr)
    if not started:
        res["result"] = "NOSTART"; return res
    if vector is None:
        ok = (not stopped) and r2 == EXPECT_R2[name]
        res["result"] = "DONE" if ok else ("STOP" if stopped else "BADREGS"); return res
    if halted:
        res["result"] = "HALT"
        if name == "sfu1h" and pc != 8 * V_DIV0:
            res["result"] = "BADREGS"; res["bad"] = ["stage1"]   # halted before the handler ran (the pre-fix shape)
    elif tailhalt:
        res["result"] = "TAILHALT"
    elif stopped:
        res["result"] = "STOP"
    elif pc != entry:
        res["result"] = "STOP"          # ran past its grace without the entry breakpoint firing
    else:
        want = dict(sxip=(fault_pc | XIP_V), psr=PSR_WANT.get(name, PSR_EXC), epsr=epsr_exp, r2=0xdeadbeef)
        if name in ("error", "trapfrozen"):
            # the second fault runs with SFRZ set: the shadows stay FROZEN at the first fault's values.  For
            # `trapfrozen' the second fault is a TRAP, which the manual (:8633-8636, 6.10 :10613-10614) exempts from
            # the ERROR re-route: it must deliver to ITS OWN vector (0x38), shadows still frozen.  M_SFRZTRAP sends it to 0x50.
            want.update(sxip=(0x10004 | XIP_V), snip=(0x10008 | XIP_V), sfip=(0x1000c | XIP_V), epsr=PSR_RESET)
        elif name == "dslot":
            # the else-arm of the delay-slot branch: SNIP = (pc + 4) | V, SFIP = delay_target | V.  br.n +16 puts
            # delay_target at 0x10014 while slot_pc+4 is 0x1000c, so the two channels are DIFFERENT numbers (with
            # br.n +8 they were both 0x1000e and M_SFIPNOTGT / M_DSLOTSWAP escaped 10/10 -- Opus, pass 2).
            want.update(snip=((fault_pc + 4) | XIP_V), sfip=((CODE + 4 + 16) | XIP_V))
            assert want["snip"] != want["sfip"], "dslot geometry collapsed: SNIP and SFIP would be one number"
        else:
            want.update(snip=((fault_pc + 4) | XIP_V), sfip=((fault_pc + 8) | XIP_V))
        bad = [k for k, v in want.items() if res.get(k) != v]
        if levelmsg:
            bad.append("level")
        res["result"] = "DELIVER" if not bad else "BADREGS"
        res["bad"] = bad
    return res

def selftest():
    s = Sess()
    ok = s.wait_prompt(0, 60)
    psr = s.cr("PSR") if ok else None
    s.close()
    return psr == PSR_RESET, psr

def main():
    ok, psr = selftest()
    print("M88KEXC_SELFTEST=%s psr_at_reset=%s (want 0x80000002)" % ("OK" if ok else "FAIL", fmt(psr)), flush=True)
    delivered = 0; total = 0; controls_bad = []
    for name, prog, regs, vector, fault_pc, epsr_exp, handler in ROWS:
        res = run_row(name, prog, regs, vector, fault_pc, epsr_exp, handler)
        print("M88KEXC_ROW=%-9s RESULT=%-8s pc=%s sxip=%s snip=%s sfip=%s psr=%s epsr=%s r2=%s%s" % (
            name, res.get("result"), fmt(res.get("pc")), fmt(res.get("sxip")), fmt(res.get("snip")),
            fmt(res.get("sfip")), fmt(res.get("psr")), fmt(res.get("epsr")), fmt(res.get("r2")),
            (" bad=" + ",".join(res["bad"])) if res.get("bad") else ""), flush=True)
        if vector is not None:
            total += 1
            if res.get("result") == EXPECT_RESULT.get(name, "DELIVER"):
                delivered += 1
        elif res.get("result") != "DONE":
            controls_bad.append(name)
        if os.environ.get("M88KEXC_VERBOSE"):
            print("---- transcript ----"); print(res.get("transcript", "")[-1200:]); print("--------------------")
    print("M88KEXC_RESULT=%d/%d" % (delivered, total), flush=True)
    if controls_bad:
        print("M88KEXC_CONTROLS=BAD %s" % ",".join(controls_bad), flush=True)
    print("M88KEXC_DONE", flush=True)
    #  exit status: the gate can rely on it (a row printing a failure word while the process exits 0 was a pass-2 finding)
    sys.exit(0 if (ok and delivered == total and not controls_bad) else 1)

if __name__ == "__main__":
    main()

        want = dict(sxip=(fault_pc | XIP_V), psr=PSR_WANT.get(name, PSR_EXC), epsr=epsr_exp, r2=0xdeadbeef)
        if name in ("error", "trapfrozen"):
            # the second fault runs with SFRZ set: the shadows stay FROZEN at the first fault's values.  For
            # `trapfrozen' the second fault is a TRAP, which the manual (:8633-8636, 6.10 :10613-10614) exempts from
            # the ERROR re-route: it must deliver to ITS OWN vector (0x38), shadows still frozen.  M_SFRZTRAP sends it to 0x50.
            want.update(sxip=(0x10004 | XIP_V), snip=(0x10008 | XIP_V), sfip=(0x1000c | XIP_V), epsr=PSR_RESET)
        elif name == "dslot":
            # the else-arm of the delay-slot branch: SNIP = (pc + 4) | V, SFIP = delay_target | V.  br.n +16 puts
            # delay_target at 0x10014 while slot_pc+4 is 0x1000c, so the two channels are DIFFERENT numbers (with
            # br.n +8 they were both 0x1000e and M_SFIPNOTGT / M_DSLOTSWAP escaped 10/10 -- Opus, pass 2).
            want.update(snip=((fault_pc + 4) | XIP_V), sfip=((CODE + 4 + 16) | XIP_V))
            assert want["snip"] != want["sfip"], "dslot geometry collapsed: SNIP and SFIP would be one number"
        else:
            want.update(snip=((fault_pc + 4) | XIP_V), sfip=((fault_pc + 8) | XIP_V))
        bad = [k for k, v in want.items() if res.get(k) != v]
        if levelmsg:
            bad.append("level")
        res["result"] = "DELIVER" if not bad else "BADREGS"
        res["bad"] = bad
    return res

def selftest():
    s = Sess()
    ok = s.wait_prompt(0, 60)
    psr = s.cr("PSR") if ok else None
    s.close()
    return psr == PSR_RESET, psr

def main():
    ok, psr = selftest()
    print("M88KEXC_SELFTEST=%s psr_at_reset=%s (want 0x80000002)" % ("OK" if ok else "FAIL", fmt(psr)), flush=True)
    delivered = 0; total = 0; controls_bad = []
    for name, prog, regs, vector, fault_pc, epsr_exp, handler in ROWS:

/*
 *  m88k_fstcr():
 *
 *  Write to a floating-point control register.
 */
void m88k_fstcr(struct cpu *cpu, uint32_t value, int fcr)
{
	switch (fcr) {

	case 63:
		/*  #298: the FPCR's RM field (bits 15:14) is now decoded by
		    the single-precision result stores, so a guest calling
		    fpsetround() -- which writes exactly this field -- is
		    doing something IMPLEMENTED, and warning "UNIMPLEMENTED"
		    for it would be dishonest (a panel seat's finding, same
		    class as #270). Warn only for bits outside RM, which
		    really are ignored.  */
		if ((value & ~(uint32_t)M88K_FPCR_RM_MASK) == 0)
			break;

		// fall through

	case 0:
	case 62:
		// Don't warn for writes with the value zero for these, for now.
		if (value == 0)
			break;

		// fall through

	default:debugmsg_cpu(cpu, SUBSYS_CPU, "m88k", VERBOSITY_WARNING,
		    "WARNING: fstcr: write 0x%08x to UNIMPLEMENTED fcr = 0x%02x (%s)",
		    value, fcr, m88k_fcr_name(cpu, fcr));
	}

	cpu->cd.m88k.fcr[fcr] = value;
}


/*
 *  m88k_memory_transaction_debug_dump():
 *
 *  Debug dump of the memory transaction registers of a cpu.
 */
static void m88k_memory_transaction_debug_dump(struct cpu *cpu, int n)
{
	uint32_t dmt = cpu->cd.m88k.dmt[n];

	debug("[ DMT%i: ", n);
	if (dmt & DMT_VALID) {
		if (dmt & DMT_BO)
			debug("Little-Endian, ");
		else
			debug("Big-Endian, ");
		if (dmt & DMT_DAS)
			debug("Supervisor, ");
		else
			debug("User, ");
		if (dmt & DMT_DOUB1)
			debug("DOUB1, ");
		if (dmt & DMT_LOCKBAR)
			debug("LOCKBAR, ");
		if (dmt & DMT_WRITE)
			debug("store, ");
		else {
			debug("load.%c(r%i), ",
			    dmt & DMT_SIGNED? 's' : 'u',
			    DMT_DREGBITS(dmt));
		}
		debug("bytebits=0x%x ]\n", DMT_ENBITS(dmt));

		debug("[ DMD%i: 0x%08" PRIx32"; ", n, cpu->cd.m88k.dmd[n]);
		debug("DMA%i: 0x%08" PRIx32" ]\n", n, cpu->cd.m88k.dma[n]);
	} else
		debug("not valid ]\n");
}


/*
 *  m88k_exception():
 *
 *  Cause an exception.
 */
void m88k_exception(struct cpu *cpu, int vector, int is_trap)
{
	bool update_shadow_regs = true;
	bool implemented = false;

	// TODO: Use a const char * instead or something like that, inside the switch...

	switch (vector) {

	case M88K_EXCEPTION_RESET:
		debugmsg_cpu(cpu, SUBSYS_EXCEPTION, "RESET", VERBOSITY_INFO, "");
		implemented = true;
		break;

	case M88K_EXCEPTION_INTERRUPT:
		debugmsg_cpu(cpu, SUBSYS_EXCEPTION, "INTERRUPT", VERBOSITY_INFO, "");
		implemented = true;
		break;

	case M88K_EXCEPTION_INSTRUCTION_ACCESS:
		debugmsg_cpu(cpu, SUBSYS_EXCEPTION, "INSTRUCTION_ACCESS", VERBOSITY_INFO, "");
		implemented = true;
		break;

	case M88K_EXCEPTION_DATA_ACCESS:
		debugmsg_cpu(cpu, SUBSYS_EXCEPTION, "DATA_ACCESS", VERBOSITY_INFO, "");
		implemented = true;
		break;

	case M88K_EXCEPTION_MISALIGNED_ACCESS:
		debugmsg_cpu(cpu, SUBSYS_EXCEPTION, "MISALIGNED_ACCESS", VERBOSITY_INFO, "");
		implemented = true;	/*  m88kexcdeliver  */
		break;

	case M88K_EXCEPTION_UNIMPLEMENTED_OPCODE:
		debugmsg_cpu(cpu, SUBSYS_EXCEPTION, "UNIMPLEMENTED_OPCODE", VERBOSITY_INFO, "");
		implemented = true;	/*  m88kexcdeliver  */
		break;

	case M88K_EXCEPTION_PRIVILEGE_VIOLATION:
		debugmsg_cpu(cpu, SUBSYS_EXCEPTION, "PRIVILEGE_VIOLATION", VERBOSITY_INFO, "");
		implemented = true;	/*  m88kexcdeliver  */
		break;

	case M88K_EXCEPTION_BOUNDS_CHECK_VIOLATION:
		debugmsg_cpu(cpu, SUBSYS_EXCEPTION, "BOUNDS_CHECK_VIOLATION", VERBOSITY_INFO, "");
		implemented = true;	/*  m88kexcdeliver  */
		break;

	case M88K_EXCEPTION_ILLEGAL_INTEGER_DIVIDE:
		debugmsg_cpu(cpu, SUBSYS_EXCEPTION, "ILLEGAL_INTEGER_DIVIDE", VERBOSITY_INFO, "");
		implemented = true;	/*  m88kexcdeliver  */
		break;

	case M88K_EXCEPTION_INTEGER_OVERFLOW:
		debugmsg_cpu(cpu, SUBSYS_EXCEPTION, "INTEGER_OVERFLOW", VERBOSITY_INFO, "");
		implemented = true;	/*  m88kexcdeliver  */
		break;

	case M88K_EXCEPTION_ERROR:
		debugmsg_cpu(cpu, SUBSYS_EXCEPTION, "ERROR", VERBOSITY_INFO, "");
		implemented = true;	/*  m88kexcdeliver  */
		break;

	case M88K_EXCEPTION_SFU1_PRECISE:
		debugmsg_cpu(cpu, SUBSYS_EXCEPTION, "SFU1_PRECISE", VERBOSITY_ERROR, "");
		break;

	case M88K_EXCEPTION_SFU1_IMPRECISE:
		debugmsg_cpu(cpu, SUBSYS_EXCEPTION, "SFU1_IMPRECISE", VERBOSITY_ERROR, "");
		break;

	case 0x80:	/*  up to OpenBSD 5.2  */
	case 0x1c2:	/*  from OpenBSD 5.3 and forward...  */
		debugmsg_cpu(cpu, SUBSYS_EXCEPTION, "syscall", VERBOSITY_INFO,
		    "r13=%i", cpu->cd.m88k.r[13]);
#if 0
		fatal("[ syscall %i(", cpu->cd.m88k.r[13]);
		m88k_cpu_functioncall_trace(cpu, 8);
		fatal(") ]\n");
#endif
		break;

	case MVMEPROM_VECTOR:
		debugmsg_cpu(cpu, SUBSYS_EXCEPTION, "MVMEPROM_VECTOR", VERBOSITY_INFO, "");
		break;

	default:
		debugmsg_cpu(cpu, SUBSYS_EXCEPTION, "unknown vector",
		    vector < M88K_EXCEPTION_USER_TRAPS_START ? VERBOSITY_ERROR
		    : VERBOSITY_INFO, "0x%03x", vector);
	}

	/*
	 *  m88kexcdeliver (2026-09-05): the seven trap-like classes above are
	 *  DELIVERED (VBR + 8*vector, SXIP = the faulting instruction, SNIP = the
	 *  next one, destination register unchanged -- MC88100 UM 6.4.3/6.5/6.6/
	 *  6.8.3), like the four this fallback never covered.  Before, any of them
	 *  stopped EVERY guest CPU here: one divu by zero, in either mode, ended
	 *  the emulation (measured: regress/m88k_exc_probe.py rows div0/udiv0).
	 *  Pre-existing upstream code (this fallback is the 0.7.0 import),
	 *  surfaced by the 2026-09-05 retrospective of #380.  What still lands
	 *  here, by design: SFU1_PRECISE/IMPRECISE (114/115; row m88kexcsfu1 --
	 *  faithful delivery needs the rest of the SFU1 exception state, which
	 *  the fork does not write) and vectors 11..113/116..127 (117 vectors
	 *  with the two SFU1 ones), which no literal-constant raise site names
	 *  but a supervisor tb0/tb1/tcnd can name directly (row
	 *  m88kexctaildefault; the probe's resid50/sfu1h rows pin that they
	 *  STILL halt).
	 */
	if (vector < M88K_EXCEPTION_USER_TRAPS_START && !implemented) {
		debugmsg_cpu(cpu, SUBSYS_EXCEPTION, "unimplemented",
		    VERBOSITY_ERROR, "vector=0x%03x pc=0x%08x",
			vector,
			(int)cpu->pc);
		for (int j = 0; j < cpu->machine->ncpus; ++j)
			cpu->machine->cpus[j]->running = false;
		m88k_pc_to_pointers(cpu);
		return;
	}

	/*  Stuff common for all exceptions:  */
	if (cpu->cd.m88k.cr[M88K_CR_PSR] & M88K_PSR_SFRZ) {
		/*
		 *  Non-trap exceptions when the shadow freeze bit is already
		 *  set result in an Error exception:
		 */
		if (!is_trap) {
			vector = M88K_EXCEPTION_ERROR;
			fatal("[ SFRZ already set in PSR => ERROR ]\n");
		}

		update_shadow_regs = false;
	} else {
		/*  Freeze shadow registers, and save the PSR:  */
		cpu->cd.m88k.cr[M88K_CR_EPSR] = cpu->cd.m88k.cr[M88K_CR_PSR];
	}

	m88k_stcr(cpu, cpu->cd.m88k.cr[M88K_CR_PSR]
	    | M88K_PSR_SFRZ	/*  Freeze shadow registers,          */
	    | M88K_PSR_IND	/*  disable interrupts,               */
	    | M88K_PSR_SFD1	/*  disable the floating point unit,  */
	    | M88K_PSR_MODE,	/*  and switch to supervisor mode.    */
	    M88K_CR_PSR, 0);

	if (update_shadow_regs) {
		cpu->cd.m88k.cr[M88K_CR_SSBR] = 0;

		cpu->cd.m88k.cr[M88K_CR_SXIP] = cpu->pc | M88K_XIP_V;

		/*  SNIP is the address to return to, when executing rte:  */
		if (cpu->delay_slot) {
			if (vector == M88K_EXCEPTION_DATA_ACCESS) {
				cpu->cd.m88k.cr[M88K_CR_SNIP] = cpu->cd.m88k.delay_target | M88K_NIP_V;
				cpu->cd.m88k.cr[M88K_CR_SFIP] = cpu->cd.m88k.cr[M88K_CR_SNIP]+4;
			} else if (vector == M88K_EXCEPTION_INSTRUCTION_ACCESS) {
				/*  If we are in a delay slot, then pc is
				    something like 0xc6000 here (not 0xc5ffc).  */
				cpu->cd.m88k.cr[M88K_CR_SNIP] = cpu->cd.m88k.delay_target | M88K_NIP_V;
				cpu->cd.m88k.cr[M88K_CR_SFIP] = 0;
			} else {
				/*  Perhaps something like this could work:  */
				cpu->cd.m88k.cr[M88K_CR_SNIP] = (cpu->pc + 4) | M88K_NIP_V;
				cpu->cd.m88k.cr[M88K_CR_SFIP] = cpu->cd.m88k.delay_target | M88K_NIP_V;
			}
		} else {
			cpu->cd.m88k.cr[M88K_CR_SNIP] = (cpu->pc + 4) | M88K_NIP_V;
			cpu->cd.m88k.cr[M88K_CR_SFIP] = cpu->cd.m88k.cr[M88K_CR_SNIP]+4;
		}

		if (vector == M88K_EXCEPTION_INSTRUCTION_ACCESS)
			cpu->cd.m88k.cr[M88K_CR_SXIP] |= M88K_XIP_E;
	}

	cpu->pc = cpu->cd.m88k.cr[M88K_CR_VBR] + 8 * vector;

	if (cpu->delay_slot)
		cpu->delay_slot = EXCEPTION_IN_DELAY_SLOT;
	else
		cpu->delay_slot = NOT_DELAYED;

	/*  Default to no memory transactions:  */
	cpu->cd.m88k.cr[M88K_CR_DMT0] = 0;
	cpu->cd.m88k.cr[M88K_CR_DMD0] = 0;
	cpu->cd.m88k.cr[M88K_CR_DMA0] = 0;
	cpu->cd.m88k.cr[M88K_CR_DMT1] = 0;
	cpu->cd.m88k.cr[M88K_CR_DMD1] = 0;
	cpu->cd.m88k.cr[M88K_CR_DMA1] = 0;
	cpu->cd.m88k.cr[M88K_CR_DMT2] = 0;
	cpu->cd.m88k.cr[M88K_CR_DMD2] = 0;
	cpu->cd.m88k.cr[M88K_CR_DMA2] = 0;

	/*  Vector-specific handling:  */
	if (vector < M88K_EXCEPTION_USER_TRAPS_START) {
		switch (vector) {

		case M88K_EXCEPTION_RESET:
			fatal("[ m88k_exception: reset ]\n");
			for (int j = 0; j < cpu->machine->ncpus; ++j)
				cpu->machine->cpus[j]->running = false;
			break;

		case M88K_EXCEPTION_INTERRUPT:
			/*  When returning with rte, we want to re-  */
			/*  execute the interrupted instruction:  */
			cpu->cd.m88k.cr[M88K_CR_SNIP] -= 4;
			cpu->cd.m88k.cr[M88K_CR_SFIP] -= 4;
			break;

		case M88K_EXCEPTION_INSTRUCTION_ACCESS:
			/*  When returning with rte, we want to re-  */
			/*  execute the instruction in SXIP, not SNIP/SFIP,  */
			/*  (unless the exception was in a delay-slot):  */
			if (!(cpu->delay_slot & EXCEPTION_IN_DELAY_SLOT)) {
				cpu->cd.m88k.cr[M88K_CR_SNIP] = 0;
				cpu->cd.m88k.cr[M88K_CR_SFIP] = 0;
			}
			break;

		case M88K_EXCEPTION_DATA_ACCESS:
			/*  Update the memory transaction registers:  */
			cpu->cd.m88k.cr[M88K_CR_DMT0] = cpu->cd.m88k.dmt[0];
			cpu->cd.m88k.cr[M88K_CR_DMD0] = cpu->cd.m88k.dmd[0];
			cpu->cd.m88k.cr[M88K_CR_DMA0] = cpu->cd.m88k.dma[0];
			cpu->cd.m88k.cr[M88K_CR_DMT1] = cpu->cd.m88k.dmt[1];
			cpu->cd.m88k.cr[M88K_CR_DMD1] = cpu->cd.m88k.dmd[1];
			cpu->cd.m88k.cr[M88K_CR_DMA1] = cpu->cd.m88k.dma[1];
			cpu->cd.m88k.cr[M88K_CR_DMT2] = 0;
			cpu->cd.m88k.cr[M88K_CR_DMD2] = 0;
			cpu->cd.m88k.cr[M88K_CR_DMA2] = 0;
			m88k_memory_transaction_debug_dump(cpu, 0);
			m88k_memory_transaction_debug_dump(cpu, 1);
			break;

		case M88K_EXCEPTION_MISALIGNED_ACCESS:
		case M88K_EXCEPTION_UNIMPLEMENTED_OPCODE:
		case M88K_EXCEPTION_PRIVILEGE_VIOLATION:
		case M88K_EXCEPTION_BOUNDS_CHECK_VIOLATION:
		case M88K_EXCEPTION_ILLEGAL_INTEGER_DIVIDE:
		case M88K_EXCEPTION_INTEGER_OVERFLOW:
		case M88K_EXCEPTION_ERROR:
			/*  m88kexcdeliver: OUTSIDE A DELAY SLOT the common path above
			    is already the architectural contract for these -- SXIP =
			    the faulting instruction, SNIP = the next one, SFIP = SNIP+4,
			    and rte resumes at SNIP (UM 6.4.3.1.4: "the processor
			    hardware does not use the SXIP on return from an exception"),
			    so the upstream doubt that sat here in an #if 0 ("should the
			    PC be backed up one step?") is answered NO: 6.5.x/6.8.3 say
			    the destination register is unchanged (6.6: and the carry
			    bit, for the overflow case), and a handler that wants
			    re-execution arranges SNIP/SFIP itself.  INSIDE a delay slot
			    the else-arm above ("Perhaps something like this could
			    work") is upstream's guess and the manual disagrees (Table
			    6-3: NIP = the branch target, FIP = target+4) -- pre-existing,
			    now reachable by ordinary faults, row m88kdslotshadow.
			    Without these labels the classes reached the default: below,
			    which stops the cpu -- the one-site fix was measured to do
			    exactly that; with them, nothing below 128 reaches that
			    default any more (it is unreachable code kept as the
			    tripwire for an eighth class).  ERROR arrives here by TWO
			    routes: the SFRZ re-route above (a fault inside a handler,
			    shadows deliberately frozen at the FIRST fault's values --
			    SXIP then names that first fault, not this one) and a
			    supervisor tb0/tb1/tcnd naming vector 10 directly (shadows
			    updated normally).  Not modelled, disclosed: scoreboard
			    capture (the shadow-update path writes SSBR = 0; a frozen
			    SSBR keeps its old value) and fcr2/fcr4/fcr5 for the divide.  */
			break;

#if 0
		// TODO: Read up more about SFU1 exceptions and how the
		// control registers look when they happen.
		case M88K_EXCEPTION_SFU1_PRECISE:
			cpu->cd.m88k.cr[M88K_CR_SNIP] = 0; //?
			cpu->cd.m88k.cr[M88K_CR_SFIP] = 0;
			//cpu->cd.m88k.cr[M88K_CR_SNIP] -= 4;
			//cpu->cd.m88k.cr[M88K_CR_SFIP] -= 4;
			break;
#endif

		default:debugmsg_cpu(cpu, SUBSYS_EXCEPTION, "m88k",
			    VERBOSITY_ERROR, "internal error");
			cpu->running = false;
		}
	}

	m88k_pc_to_pointers(cpu);
}
