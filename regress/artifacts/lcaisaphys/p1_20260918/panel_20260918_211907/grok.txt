## Premises that held

- **Not shipped.** Checkpoint HEAD is `e0be9b2`; `dev_lca.c` last changed in `#530` (`8bd97e4`). The two nested calls still pass `CACHE_NONE` only (`dev_lca.c` write `return cpu->memory_rw(..., CACHE_NONE)`, read the same).
- **`PHYSICAL` is the only skip.** `memory_rw.c`: `if (misc_flags & PHYSICAL || cpu->translate_v2p == NULL) paddr = vaddr; else translate_v2p(...)`. `PHYSICAL` is `32`.
- **Inner address is not K0SEG.** `LCA_PCI_SIO = 0x1c0000000`, `LCA_ISA_BASE = 0x1d0000000`. Port `0x3fd` → inner `0x1d00003fd`. K0SEG is `0xfffffc0000000000`..`0xfffffdffffffffff`. `0x1d00003fd` is in **USEG** (`0`..`0x000003ffffffffff`), so it **walks** once `ptbr != 0`.
- **Identity hacks are both `!userMode`.** K0SEG identity and `base == 0` identity each require `!userMode`. `base = apcb_ptbr << 13`, so `ptbr == 0` iff `base == 0`. The brief's settled line dropped that conjunct; it does not matter for this probe (`swpctx` loads PCB fields and does **not** write `cpu->cd.alpha.ps`).
- **ISA targets are `DM_DEFAULT`.** `ns16550`, `8253`, `8259`, `pccmos`, `pckbc` all register `DM_DEFAULT`. `NO_EXCEPTIONS` therefore skips the handler (`!no_exceptions || DM_READS_HAVE_NO_SIDE_EFFECTS` is false).
- **Registration is physical.** `DEVINIT(lca)` passes `LCA_ISA_BASE` to `bus_isa_init` as `isa_portbase`; COM1 is `isa_portbase + 0x3f8`.

## Premises that need a qualifier

1. **Failure mode is the unmapped case only.** With an invalid L1, a read is a successful false zero (`#244` zeroes the inner byte; the read arm **ignores** the inner return and `return 1`); a write is abandoned (`write` arm `return`s `MEMORY_ACCESS_FAILED == 0`; Alpha has no `MEM_MIPS`/`MEM_M88K` fault in that block) **and** each miss prints the unlatched `wasn't found` line. If a guest has a **valid** PTE for VA `0x1d00003fd` (legal in USEG), the inner access is a **silent misroute into guest memory**, not a miss. Same missing token; worse symptom. This witness does not cover that cell (and does not need to, for reproduction).

2. **`CACHE_NONE | PHYSICAL` and bare `PHYSICAL` are not the same encoding.** `CACHE_NONE` is **`2`**, not `0`. `cache = misc_flags & 0x3` is `2` vs `0` (`CACHE_DATA`). They are equivalent **at this site** (enumerated below), not identical.

3. **The `56` census** was not re-counted here. The two `CACHE_NONE | PHYSICAL` sites in `dev_ps2_stuff.c` exist. The older note that `dev_sh4.c` / `dev_pccmos.c` / Maple already used that pair is correctly withdrawn.

## Q1 — premise audit

**Is the nested address ever legitimately virtual?** No. The guest never names `0x1d0000000`. It names the sparse window (`LCA_PCI_SIO + (port << 5)`), typically via K0SEG. `lca_isa` **constructs** `LCA_ISA_BASE + port` as the address `bus_isa_init` registered. A guest PTE covering `0x1d0000000` would be a collision with an emulator-internal physical, not a contract.

**Sibling with the same shape** (device-constructed physical, `memory_rw` without `PHYSICAL`): in `src/devices/`, the only other `CACHE_NONE`-and-no-`PHYSICAL` call is `dev_ether.c` (guest-written `idata` as a DMA destination). That is a **guest pointer**, not a constructed PA. PROM/arcbios `CACHE_NONE` calls are also guest VAs and are correctly virtual. I did not find a second constructed-PA forward missing `PHYSICAL`. (Did not census `src/promemul` beyond the arcbios hits.)

**Severity: HIGH, not MED.** This is not a rare encoding. Every Alpha OS writes a non-zero PTBR; from that moment the entire sparse ISA window (console UART at `0x3f8`, 8042, PIC, PIT, CMOS) is dead, and every access floods. Host process stays up (`fatal()` prints). Alpha already has no interrupt delivery (`#516`), so **polled ISA is the remaining I/O** — this round kills that. HIGH.

**(d) enumerated, as asked.** After `PHYSICAL`, translate is skipped. Remaining `cache` uses:

1. `FLAG_INSTR` on translate — skipped.
2. `#ifdef MEM_MIPS` R3000 cache block — **not in the Alpha unit**.
3. Device-found path (`paddr` in some `devices[i]`) — **`cache` is never read** (dyntrans install keys on `DM_DYNTRANS_OK`, which these ISA devices do not have).
4. `paddr >= physical_max` (device miss): `memory_warn_about_unimplemented_addr`, then zero-fill on read, `goto do_return_ok`. The only `cache != CACHE_NONE` test there is inside `#if 0` **and** `MEM_MIPS`.
5. RAM path (`paddr < physical_max`): `update_translation_table` uses `cache == CACHE_INSTRUCTION`; `invalidate_code_translation` also fires on **read** when `ok == 2 && cache == CACHE_DATA`. **This handler never forwards into RAM** (`0x1d0000000 + port` is ~7.25 GB; `-M 64` is 64 MB).

So (d) is equivalent **here**. It would **not** be equivalent if the inner address ever became RAM: bare `PHYSICAL` makes `cache == CACHE_DATA` and a read would invalidate code translations. Keeping `CACHE_NONE` is the right extra token, not an idiom appeal.

Floor note for the later detector: (a) and (b) are the two single-site reinstatements; (c) is a joint-flag mutant that greens the miss rows; (d) is equivalent (disclose, do not demand a row); (e) is a conditioned predicate on the port.
