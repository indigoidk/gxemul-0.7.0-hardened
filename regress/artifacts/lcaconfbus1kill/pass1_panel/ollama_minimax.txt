That branch is exercised today on real (bus-0) traffic and works (premise 1's bus-0 row), so the interpretation is forced. `tag = (relative_addr >> 5) & ~0xff` therefore recovers the comment's logical PCI tag, and `dev = (tag >> 11) & 0x1f` extracts bits 15..11 — the type-1 device field. **Q3 — IMPLEMENT vs alternatives.** REASONED. IMPLEMENT is the only member that degrades correctly if a device is ever placed on bus 1. DECLINE / latched-announce / explicit-all-ones are observationally identical today (empty bus, all-ones) but would silently mis-route a real bus-1 device. **Q4 — the discriminating row.** REASONED. `0xffffffffffffffff` on the armed read separates IMPLEMENT / explicit-all-ones from any DECLINE variant (which would read as 0). The row is best-available; record the conflation as a known limit, not a defect in the witness.
