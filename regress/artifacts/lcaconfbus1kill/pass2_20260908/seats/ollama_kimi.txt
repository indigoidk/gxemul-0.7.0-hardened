**On indistinguishability: the author is right about value and stderr, and has missed one channel.** Read value: refused returns all-ones-at-reg-0 / 0-elsewhere; forwarded-to-NULL returns the same (P1); type-0 empty-slot the same. ## Q2

(a) **Silence is defensible; a `(once)` latched announce on the discarded write only is better.** Type-1 probing of bus 0 is legitimate guest behavior; per-access spam on reads would be wrong. (b) **The asymmetry is real but defensible; sibling-parity is only half-breached.** `bus_pci`'s own contract (P1) is already asymmetric — reads silent, writes noisy. The refuse arm is silent in both directions, so it matches the read half and diverges from the write half. Given a 255-bus probe sweep would print the neighboring diagnostic 255 times anyway, silence on the structurally-invalid bus-0 case is the smaller sin. Non-blocking; `(once)` on the write-discard closes it.

(c) **Yes, disclose — and the premise underneath is not checkable from the packet.** The brief asserts `memory_rw.c` has no Alpha bus-error dispatch; the packet contains no line of `memory_rw.c`, so "FAULT is unavailable" is READ-as-asserted. A guest that probes config space by *catching the exception* will behave differently on model vs metal; that belongs in the CHANGELOG entry. The diff's comment currently claims the refusal "matches the empty-slot contract" — true — and should add "and diverges from real-hardware master-abort semantics" to stay honest.
