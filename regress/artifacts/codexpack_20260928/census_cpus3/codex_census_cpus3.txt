The bank switches accept these values: **0x10 USR32, 0x11 FIQ32, 0x12 IRQ32, 0x13 SVC32, 0x17 ABT32, 0x1b UND32, 0x1f SYS32** (`src/include/cpu_arm.h:108–114`; `src/cpus/cpu_arm.c:525–557`; `src/cpus/cpu_arm.c:572–604`). Guest mode-changing paths save the old bank, write CPSR, and load the new bank; therefore the load exit prevents an unsupported mode from surviving to a subsequent save (`src/cpus/cpu_arm_instr.c:838–847`; `src/cpus/cpu_arm_instr.c:1805–1812`; `src/cpus/cpu_arm_instr_dpi.c:218–232`). User-mode MSR applies `"mask &= 0xff000000;"`, excluding the mode field (`src/cpus/cpu_arm_instr.c:826–827`).

The debugger bypass is separate: `"CPU_SETTINGS_ADD_REGISTER32(\"cpsr\", cpu->cd.arm.cpsr);"` exposes CPSR as writable storage (`src/cpus/cpu_arm.c:196`; `src/include/cpu.h:535–537`). Debugger assignment passes writeflag `1`, and the settings writer directly assigns the supplied value (`src/debugger/debugger.c:248`; `src/core/settings.c:230–232`). Thus line 561 is debugger-inducible after resume, although it is not independently guest-reachable.

Line 1219 is not merely an internal assertion: the Thumb MOV-to-PC branch writes `"cpu->pc = addr - sizeof(uint16_t);"` after updating T; the normal tail then adds `sizeof(uint16_t)`, leaving the even `addr` established at entry. The next dispatcher checks T alone (`src/cpus/cpu_arm.c:1214,1515–1520,1814`; `src/cpus/cpu_dyntrans.c:255–260`). Ordinary control flow can therefore reach it.

For MMU faults, the translator already calls `arm_exception` before returning failure. The remedy must preserve that exception, without delivering it twice (`src/cpus/memory_arm.c:268–276`; `src/cpus/memory_rw.c:248–268`). The literal-load branch additionally passes `"CACHE_INSTRUCTION"`, selecting the prefetch-abort path for a data load (`src/cpus/cpu_arm.c:1548–1555`; `src/cpus/memory_arm.c:268–273`).
