The following evidence qualifies the classifications.

**Privilege and dispatch.** ARM’s decoder selects `cond_instr(mcr_mrc)`; its execution wrapper calls `arm_mcr_mrc`, whose installed-handler dispatch contains no mode check. Thus “user” reflects this implementation, including the system-control accesses. CP6 requires an installed handler; IQ80321 and Iyonix install it. (`src/cpus/cpu_arm_instr.c:4969-4985`, `src/cpus/cpu_arm_instr.c:948-955`, `src/cpus/cpu_arm.c:2643-2663`, `src/machines/machine_iq80321.c:57`, `src/machines/machine_iyonix.c:64`.)

MIPS `X(tlbw)` checks coprocessor availability, but the check rejects user mode only when CU0 is clear; otherwise it returns success. This is why the runtime rows are not unconditionally labelled privileged. (`src/cpus/cpu_mips_instr.c:2676-2683`, `src/cpus/cpu_mips_instr.c:88-110`.)

**The two unreachable MIPS exits.** The executing caller of `coproc_function` supplies CP1; the disassembly caller supplies `unassemble_only=1`. COP1 branches select `instr(cop1_bc)` and leave that decoder case; the separately selected slow-path cases exclude those branches. Consequently the current callers cannot reach either legacy execution termination. (`src/cpus/cpu_mips_instr.c:2585-2589`, `src/cpus/cpu_mips.c:1336-1338`, `src/cpus/cpu_mips_instr.c:5044-5115`.)

**The old-entry MIPS exit is conditionally reachable.** Normal guest installation of a valid small-page entry encounters `:2169` first, but construction can seed the old entry independently:

- A selected CPU name survives defaulting and reaches CPU creation; R4100 is a supported CPU-table entry. PICA normally defaults to R4000. (`src/core/emul.c:487-502`, `src/include/mips_cpu_types.h:78`, `src/machines/machine_arc.c:261-262`.)
- ARC PROM setup invokes `arcbios_init`, which invokes the component setup containing PICA’s predefined mappings. (`src/machines/machine_arc.c:250-253`, `src/promemul/arcbios.c:3187`, `src/promemul/arcbios.c:2087-2105`.)
- The relevant predefined mapping explicitly has **index 10, size 4096, valid0 1**. The mask values are **4096 → 8191 (`0x1fff`) → stored mask 0** under `(2*size - 1) & ~0x1fff`; R4100 normalization then produces **`0x7ff`**. Validity is retained. Replacement of that setup-seeded entry reaches the old-entry guard. (`src/promemul/arcbios.c:2129-2131`, `src/cpus/cpu_mips_coproc.c:482-490`, `src/cpus/cpu_mips_coproc.c:2030-2041`.)

This establishes a source-derived route with a nondefault PICA/R4100 configuration; execution was not checked.

**ARM remedies need distinctions.** The blanket PC-register check covers more than malformed transfers: the permitted ARM manual documents optional ARMv5 cache test/clean operations whose destination is PC and whose result updates Z. Its general CP15 rule separately calls R15 transfers “UNPREDICTABLE.” Model-specific handling is therefore required. (`src/cpus/cpu_arm_coproc.c:60-62`; on-disk `C:\DocumentNoSnc\CC\GXEMUL\_scratchpad\ddi0100i.txt:27697-27700`, `:32653-32674`.)

The CP6 catchall also includes a named register: the committed header says **`FINTSRC cp6 c9,0`**, while the handler’s corresponding switch accepts only **0, 4, 8**. Blanket UND would therefore reject a register explicitly named by the project’s hardware header. (`src/include/thirdparty/i80321reg.h:319`, `src/cpus/cpu_arm_coproc.c:309-335`.)

The endianness exit cannot simply be deleted: its comment calls it **“LOAD-BEARING”** and identifies translation invalidation and instruction retranslation requirements. The control-write path admits opcode2 values **0, 2, 3, 4, 5, 6, 7**; value **1** takes the auxiliary-control return. (`src/cpus/cpu_arm_coproc.c:107-135`, `src/cpus/cpu_arm_coproc.c:163-174`.)

ISRC write semantics and the complete XScale CP14 selector specification were **not checked**. Their proposed remedies remain provisional. Existing interrupt code binds ISRC to interrupt status and changes IRQ assertion from status and enable, so the assignment before `:331` alone does not establish correct behaviour. (`src/devices/dev_i80321.c:83-94`, `src/devices/dev_i80321.c:445-446`, `src/cpus/cpu_arm_coproc.c:329-331`.)
