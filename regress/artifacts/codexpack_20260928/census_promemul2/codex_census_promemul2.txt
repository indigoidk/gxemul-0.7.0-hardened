The runtime and construction distinctions rest on these caller checks:

- **OF is user reachable.** The ARM and PPC decoders select their firmware handlers without a privilege gate; those handlers call `"of_emul(cpu);"` (`src/cpus/cpu_arm_instr.c:4991-5003`, `src/cpus/cpu_arm_instr.c:972`; `src/cpus/cpu_ppc_instr.c:4397-4405`, `src/cpus/cpu_ppc_instr.c:3958`). The architecture values of those callers are exactly **{ARM, PPC}**, explaining the unreachable architecture defaults.
- **Missing OF state is a runtime case.** Machine allocation uses `"memset(m, 0, sizeof(struct machine));"` (`src/machines/machine.c:67`). MacPPC setup executes `"if (!machine->prom_emulation)"` and returns before its OF initializer (`src/machines/machine_macppc.c:93-99`). The instruction handlers above do not enforce that setup condition.
- **OF tree mutation is construction work.** The device/property helpers feed the initializer functions, reached from MacPPC setup (`src/promemul/of.c:704`, `src/promemul/of.c:721`, `src/promemul/of.c:734`, `src/promemul/of.c:762`, `src/promemul/of.c:794`, `src/promemul/of.c:859`, `src/promemul/of.c:969`; `src/machines/machine_macppc.c:99-105`).

The manual child helper is explicitly documented as `"Used internally to set up component structures."` (`src/promemul/arcbios.c:836`). - **ARC’s unreachable guards remain setup invariants.** The initializer’s callers are ARC and SGI setup (`src/machines/machine_arc.c:253`; `src/machines/machine_sgi.c:682`).
