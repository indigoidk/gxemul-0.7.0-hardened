**Copy the mask expression as the positive-width branch, not as the entire BFI repair.** The smallest clear replacement sketch is:

```c
/*
 * ARMv7-A/R A8.8.20 makes msb < lsb UNPREDICTABLE.
 * Emulator policy: preserve the destination for those encodings.
 */
uint32_t mask = (width <= 0) ? 0U :
    ((width == 32) ? 0xffffffffU : ((1U << width) - 1));
```

The existing subsequent mask shift and destination merge can remain. The decoder bounds `lsb` to `0..31`; `x` and `mask` are unsigned 32-bit values. Enumeration gives 496 zero-mask selections, one full-mask selection, and 527 unsigned shifts with counts `1..31`.

This policy silently preserves the destination and continues execution. The comment may attribute **UNPREDICTABLE** to ARM; it must attribute **destination preservation** to the emulator. Also, width zero already produced a zero mask without C UB. It is not an architectural “wrong result” merely because its ordering is invalid.

**The vacuity distinctions matter:**

- Both width-31 rows commonly return the correct value even with the original signed expression. They protect semantics but **do not detect the signedness defect**.
- The zero-width row passes the original implementation because its mask is already zero. It is a policy boundary check, not a negative-shift detector.
- Interior and one-bit rows also pass the original implementation. Their purpose is to catch damage introduced by a repair.
- A full-width row seeded with equal source and destination values is vacuous against a zero-mask/no-op outcome. This includes zero/zero and full-width source/destination aliasing.
- Invalid-order rows with zero source and zero destination can likewise pass despite the defect. The contrasting seeds above avoid that particular weakness under the count-masked lowering discussed by #510.
- **None of those lowering predictions is a BFI measurement from this review.** Undefined C behavior provides no portable defective-result oracle.

A compatibility row has value when its claim is explicit. Calling it proof that the original UB is detected would be the mistake.
