**The concrete fixture uses these values.**

Let `W(offset, value)` and `R(offset)` mean actual 32-bit guest stores and loads at `M + offset`.

```text
M       = 0xa05f6c00       Maple registers through P2
A       = 0x13579bdf       all five low bits set
B       = 0xeca86420       complement of A; aligned

P1      = 0x0c001400       physical address of one descriptor
P2      = 0x0c001480       physical address of two descriptors

R1      = 0x0c001800       first transfer's receive buffer
R2      = 0x0c001a00       second transfer, descriptor 1 receive buffer
R3      = 0x0c001c00       second transfer, descriptor 2 receive buffer

SCRATCH = 0x0c001f00       execution control
MARKER  = 0x0c001f04       per-block completion marker
POISON  = 0xa5a55a5a       preset destination of each register load
```

The relevant offsets are `0x04` for DMA address, `0x14` for enable, and `0x18` for the trigger. The device registers physical base `0x005f6c00` in [device initialization](C:/DocumentNoSnc/CC/GXEMUL/GXEMUL-SEC/src/devices/dev_dreamcast_maple.c:644).

Access descriptor and receive RAM through its uncached guest alias, while putting **physical addresses** in descriptors and `MAPLE_DMAADDR`. Reserve 512 bytes for each receive buffer, and require the expected response to fit. These locations are below the probe’s stated ELF load address; its existing instruction area starts at `0x8c001000`. See the [probe’s memory layout](C:/DocumentNoSnc/CC/GXEMUL/GXEMUL-SEC/regress/gdrom_default_probe.py:189).

`A` is an unaligned **register value**. The access to the register itself remains aligned. No DMA is triggered while `A` or `B` is programmed.

Use **`MAPLE_COMMAND_DEVINFO`, port A, main unit**. Port A has the controller attached, and the command produces a response header followed by its device information. This is deterministic and needs no queued controller input. See the [DEVINFO response path](C:/DocumentNoSnc/CC/GXEMUL/GXEMUL-SEC/src/devices/dev_dreamcast_maple.c:471) and [port attachments](C:/DocumentNoSnc/CC/GXEMUL/GXEMUL-SEC/src/devices/dev_dreamcast_maple.c:654).

Define a 12-byte descriptor `D(receive, last)`:

| Descriptor-relative offset | Bytes |
|---|---|

| `+4` | `receive`, encoded little endian |
| `+8` | `MAPLE_COMMAND_DEVINFO, 20, 00, 00` |

Thus the port is zero, the GUN bit is clear, the receiver selects main unit zero, and `datalen_cmd` is zero.
