## 4. KILL TABLE — internally consistent once CI source-read semantics are correctly modeled

This is the part I had to work hardest at. The key insight the brief leaves implicit:

- **CI source-read** returns the **first byte** of the big-endian source word (byte 0), not the low byte. For source `0x1a2b3c4d` stored big-endian, CI source-read gives `0x1a`, not `0x4d`.
- **CI destination-write** assigns `buf[0] = colour`, where `colour` is whatever the source-read produced.
- **RGBA source-read** returns the full 32-bit value; **CI destination-write** then takes `colour & 0xff`.

With that model:

| Mutant | Kills (per model) | Score | Matches brief? |
|---|---|---|---|
| M1 (depth==4) | fill top, fill bot, copy 2nd, copy 4th | 9/13 | ✓ |
| M2 (no dst RGBA) | fill top, fill bot, copy top, copy 2nd, copy 4th | 8/13 | ✓ |
| M3 (no src RGBA) | copy top, copy 2nd, copy 4th | 10/13 | ✓ |
| M4 (depth==32 && COPY) | fill top, fill bot, copy 2nd, copy 4th | 9/13 | ✓ if COPY bit is unset for the detector's copy (see below) |
| M5 (dst RGB) | fill bot, copy 4th | 11/13 | ✓ (requires RGB to leave alpha as 0/stack, not source byte 3) |
| M6 (depth>=16) | depth16 top | 12/13 | ✓ |
| M7 (depth!=8) | depth16 top | 12/13 | ✓ |
| M8 (src RGB) | copy 4th | 12/13 | ✓ (requires RGB source-read to zero alpha) |

**M1–M4 each come in exactly one lower than predicted, from `copy 4th` gating** — the brief's explanation is consistent with the model. **READ.**

**One thing the brief does not say but the model implies:** M4 only equals M1 if `(mode & COPY)` is **never true** in the detector's copy operation. If the detector's copy does set the COPY bit, M4 applies the fix to copies and `copy 2nd`/`copy 4th` would pass, giving M4 a score of 11/13, not 9/13. The brief's "as M1" is a factual claim about the detector's mode register that I cannot verify from the packet. **NAME THIS:** the premise "M4 reproduces pre-fix because `(mode & COPY)` is false for the detector's copy" is the single fact that would settle whether M4's score is 9/13 or 11/13.
