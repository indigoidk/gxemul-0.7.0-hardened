*** WHY #481'S SINGLE ABORT ROW LET EIGHTEEN MUTANTS THROUGH -- and the reason is the
    opposite of the intuition. ***

That row armed write_in_progress, atapi_cmd_in_progress, the phase AND the ring together,
then asserted all four were cleared.  Any single-conjunct qualification of the helper call
still passed it.

  A ROW THAT ARMS MORE STATE IS WEAKER AGAINST GUARD OVER-RESTRICTION, NOT STRONGER.
  More state satisfies more guards.  A composite row is maximally satisfying and therefore
  minimally discriminating.

MEASURED TWICE, and both went against the author's reasoning:

  Md_nohelper (the abort removed)           4 red -- the composite row is NO LONGER SOLE
  Mo_conj (abort only if BOTH are live)     3 red -- the composite row DOES NOT RED, because
                                                     it arms both, satisfies the conjunction,
                                                     and the abort runs

So the composite row is blind to over-restriction in BOTH directions tested.  It is KEPT --
two shapes is not a proof of general redundancy, the ADDITION LICENCE has a mirror, and it
remains the only row asserting all four clears happen together.  Both measurements are
preserved (NOHELPER_100row.out, CONJUNCTIVE_100row.out) so a future round proposing deletion
starts from evidence and knows which shapes were tried.

THE DISCRIMINATOR FOR FUTURE ROWS, cheap enough to apply at construction:
  *Does this row assert that something HAPPENED, and did I arm more than the minimum needed
  to make it happen?*
A row asserting state PERSISTS is not affected -- arming more gives it more that could be
wrongly cleared.  A sibling audit found this class has EXACTLY ONE MEMBER in the file, and
it is the one #482 repairs.
