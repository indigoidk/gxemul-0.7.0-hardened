3. THE CLOSED ENUMERATION (what PRETABLE_5 carries, what table 5 measures)
The class L: one inserted statement `if (G) T op V;` (or one gate added to the existing latch sets at :116 and :135 or the notice predicates at :129 and :132), with
 position P in {H head (after the fold, before the switch), CI chipid arm, CR chiprev arm, MT memconf arm top, MW memconf write block before the test, MB memconf latch body, DT default arm before the test, DB default latch body, DA default arm after the test block, TL tail} (10);
 target T in {M = warned_memconf, D = warned_default} (2), or a field F in {chipid, chiprev, memconf} for keep-forms;
 op V in {= 1 (set), = 0 (clear), = idata, ^= 1, ^= idata} for latches; {=, |=, ^=, &=} idata for fields;
 gate G: ANY boolean function of the four tests the function itself makes (direction :70, controller :73, M :112, D :127), including always; plus single idata-bit tests (set or clear, b = 0..31) at MT/MW/MB/DT/DB/DA/H/TL; plus single offset-bit tests (m = 0..7) at DT/DB/DA/H/TL (constants in the served arms).
Why it is finite and how each cell is killed. The latches are observed only at memconf stores (M) and default accesses (D). Define the four phases by (M, D) = 00, 10, 01, 11. A set-form of T fires visibly iff some access of its kind reaches P with T clear and a first access of T's category follows; a clear-form iff the access happens with T set and a same-category access follows (silent on the fix). So the closure condition is: every access kind (arm x direction x controller, with store values 0x00 and 0xff for byte stores and 0xffffffff for the wide ones) occurs in EVERY phase, with a memconf store and a default access after each phase. Because the exposure set is the full product of kinds and phases, every gate over {direction, controller, M, D} is covered at once, not only single predicates. Value bits: each notice category's first store takes 0x00, 0x07, 0xff and 0xffffffff in a session that then makes a second same-category access; a store of 0xffffffff and a read (idata 0) occur in every phase at the memconf arm and the default arm. Offset bits: first default reads at {0x0c, 0x7c, 0xff, 0xf3} and first default writes at {0x18, 0xe7, 0x1c}; non-first default accesses at 0x7c and 0x83 between memconf stores and at 0x0c, 0xf3, 0x1c before a first memconf store (complement pairs, every bit set and clear in each role). Parity: every phase makes three stores per served arm (one 0xff on controller 1 in set phases is placed first; the controller-0 pair ends on 0xff in clear-detecting... see the lists) so constant toggles under a single gate flip an odd number of times before the phase's observation.
