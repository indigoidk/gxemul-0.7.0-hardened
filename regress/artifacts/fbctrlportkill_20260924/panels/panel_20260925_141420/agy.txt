#### 1. The Floor & DEPENDS-ON Enumeration (73-Row Composite vs. Disclosed Escapes)
* **Question:** Is there an edit inside the `DEPENDS-ON` enumeration—predicates dominating the fixed arm ([`writeflag == MEM_READ`](file:///C:/DocumentNoSnc/cc/GXEMUL/GXEMUL-SEC/src/devices/dev_fbctrl.c#L118), [`idata >= DEV_FBCTRL_NPORTS`](file:///C:/DocumentNoSnc/cc/GXEMUL/GXEMUL-SEC/src/devices/dev_fbctrl.c#L120), [`!d->warned_port`](file:///C:/DocumentNoSnc/cc/GXEMUL/GXEMUL-SEC/src/devices/dev_fbctrl.c#L128)), weakened or qualified, or operands swapped with fields the body reads ([`idata`](file:///C:/DocumentNoSnc/cc/GXEMUL/GXEMUL-SEC/src/devices/dev_fbctrl.c#L110), [`current_port`](file:///C:/DocumentNoSnc/cc/GXEMUL/GXEMUL-SEC/src/devices/dev_fbctrl.c#L50), [`warned_port`](file:///C:/DocumentNoSnc/cc/GXEMUL/GXEMUL-SEC/src/devices/dev_fbctrl.c#L52), [`port[]`](file:///C:/DocumentNoSnc/cc/GXEMUL/GXEMUL-SEC/src/devices/dev_fbctrl.c#L51))—that scores 73/73 and is NOT one of the eight disclosed in the contract?
* **Finding:** **No.** Every non-disclosed modification within the strict dominating predicate/body-read field enumeration is caught by the 73-row suite or is an equivalent no-op:
  - Swapping operands in `writeflag == MEM_READ` with `idata`, `current_port`, or `warned_port` turns read accesses into writes or vice-versa, failing [`C LIVENESS`](file:///C:/DocumentNoSnc/cc/GXEMUL/GXEMUL-SEC/regress/fbctrl_port_probe.py#L418) or Session A round-trip readbacks.
  - Swapping operands in `idata >= DEV_FBCTRL_NPORTS` with `current_port` (initially 0), `warned_port` (0 or 1), or `port[]` causes either universal storage (killed by [`M_store`](file:///C:/DocumentNoSnc/cc/GXEMUL/GXEMUL-SEC/regress/artifacts/fbctrlportkill_20260924/table3/TABLE.out#L27): 52/73) or universal refusal of legal selectors at power-on (killing Session A's `accept selector 0 written by sw`).
  - Swapping operands in `!d->warned_port` with `!d->current_port` (evaluates to false when `current_port == 5` in Session P) silences announces in Session P, failing `announce: exactly 1 right after the FIRST refusal`.
  - Qualifying `!d->warned_port` with `&& idata >= DEV_FBCTRL_NPORTS` or `&& d->current_port >= 0` is an identical binary/no-op, because `current_port` is constrained to `0..7` and the refusal block is already guarded by `idata >= 8`.
  - Qualifying with `!d->warned_port && d->current_port != 0` suppresses the announce at power-on (`current_port == 0`), killing `F refusal announced while free-running (fatal)`.
  - Narrowing/weakening `idata >= DEV_FBCTRL_NPORTS` by width or bit-range is fully covered by the closed width table (`T_W_*`, `T_X_w8`, `T_D2_mask63`, `M_gt`, `M_wide`, `M_u32`, `M_i32`, `M_i64`).

    - Check 6 fails (`grep -c '^  FAIL '` is $\ge 1$, expected 0).
    - Check 8 fails (`grep -c '^  ok '` is $\le 72$, expected 73).
  - **Adversarial / tampered log condition: YES.** The gate reconciliation rows ([`gate_mips_folds.sh:470-473`](file:///C:/DocumentNoSnc/cc/GXEMUL/GXEMUL-SEC/regress/gate_mips_folds.sh#L470-L473)) count line occurrences:
    ```bash
    check "fbctrl_port rows emitted match the trailer total" "$(grep -cE '^  (ok|FAIL) ' "$FBCLOG")" "${fbres#*/}"
    ```
