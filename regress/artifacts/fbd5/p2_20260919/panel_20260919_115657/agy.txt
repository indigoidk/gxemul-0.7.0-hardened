### Q2. THE SMALLEST EDIT THAT BREAKS THIS AND STILL PASSES

**The Edit:**
In [`src/devices/dev_footbridge.c`](file:///C:/DocumentNoSnc/CC/GXEMUL/GXEMUL-SEC/src/devices/dev_footbridge.c#L585), restrict the warn-once latch on any of the other four sites to 32-bit accesses with `&& len == 4` (e.g., at `case IRQ_RAW_STATUS`):
```c
case IRQ_RAW_STATUS:
	if (writeflag == MEM_READ)
		odata = d->irq_status;
	else if (!d->warned_irq_raw_w && len == 4) {
		d->warned_irq_raw_w = 1;
		fatal("[ footbridge write to irq_raw_status (once) ]\n");
	}
	break;
```

**Why it breaks the contract:**
If a guest or harness performs a byte write (`len == 1`) to `IRQ_RAW_STATUS` (+0x184) as its first access, the access falls through silently without setting `warned_irq_raw_w` and without announcing via `fatal()`, violating the requirement to announce every undefined-direction access once regardless of access width.

**Why all tests stay GREEN:**
1. **Offline Differential (`regress/diff_footbridge.c`):**
   - In P1–P5 (lines 482–503), the loop accesses each site with `dec[i].len = 4` on access #1, which satisfies `len == 4`, sets `warned_irq_raw_w = 1`, and increments `fatal_calls`.
   - The subsequent byte (`len == 1`) and halfword (`len == 2`) accesses at lines 498–500 occur *after* the latch is already set. Because the test checks `fatal_calls - f0 == 0`, falling through without calling `fatal()` passes whether or not `len == 4` is present.
   - P9 (lines 522–534) initializes a fresh instance with a byte write as the *first* access, but P9 **only** tests `IRQ_STATUS` (+0x180). It does not test `IRQ_RAW_STATUS`, `IRQ_ENABLE_CLEAR`, `FIQ_STATUS`, or `FIQ_RAW_STATUS`.
2. **Guest Probe (`regress/footbridge_sites_probe.py`):**
   - In `SITES` (lines 220–245), all stores and loads are standard 32-bit `_str` (`0xE5800000`) and `_ldr` (`0xE5900000`) instructions (`len == 4`). There is not a single `ldrb`, `strb`, `ldrh`, or `strh` in Arm S.
3. **Gate (`regress/gate_arm.sh`):**
   - Gate pins verify N0–N5, S1–S5, SF1–SF2, and H1–H2. Every row remains green.
