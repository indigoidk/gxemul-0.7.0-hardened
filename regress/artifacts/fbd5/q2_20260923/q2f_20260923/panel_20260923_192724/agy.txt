```c
if (writeflag == MEM_WRITE)
```
to:
```c
if (writeflag == MEM_WRITE && (len & 1) == 0)   /* ignores odd lengths */
```
or conditioning on a length never generated by the architecture load/store unit (such as `len != 3` or `len <= 4`).
- **Detection**: ARM memory accesses emit `len` in `{1, 2, 4, 8}`. The detector tests `len` in `{1, 2, 4}` for Clear writes. A condition that filters out un-emitted lengths like `len == 3` cannot be observed.
- **Contract disclosure**: The contract specifies the domain of width as "what the ARM load/store unit emits -- 1, 2 and 4, and 8 at the 8-byte-aligned offsets" ([`diff_footbridge.c:883-884`](file:///C:/DocumentNoSnc/cc/GXEMUL/GXEMUL-SEC/regress/diff_footbridge.c#L883-L884)), correctly bounding the domain to architectural values.
