For **Q5**, **I would not build a class-wide gating checker from this sweep.** My broad signal screen selected 79/79 files. The 13/25 findings are a deliberately selected sample, not checker precision or class prevalence; recall across ~95 helpers remains unmeasured.

Several suggested signals also have legitimate uses: `got if alive else "died"` can fail correctly; first-match selection can be intentional; greedy hexadecimal `+` consumes extra hexadecimal digits, unlike `{8}`. `gdrom_default`’s boolean `accept dma` asserts arming and has a separate data-value row.

A useful mechanical check would have a narrower claim: test an extracted parser against missing output, echo-only output, longer numeric tokens, duplicate samples, and distinct before/after samples. Before making anything a gate, evaluate it on frozen positive and negative examples and report misses by class. An AST search could help rank candidates; it should not certify absence of vacuity.
