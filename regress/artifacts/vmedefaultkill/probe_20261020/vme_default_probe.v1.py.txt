#!/usr/bin/env python3
"""vme_default_probe.py -- DRAFT rung-3 DETECTOR for dev_vme.c's `default:' arm (vmedefaultkill).

STATUS.  A DRAFT, built 2026-10-20 from the round's pass-1 DESIGN brief (section 6, the
detector plan) against the section-5 implementation SKETCH, which is under panel review.
Every `want' below is the SKETCH's behaviour, not a ratified fix.

DEFECT (HEAD 5dbc000e; dev_vme.c is byte-identical to the 0.7.0 import).  DEVICE_ACCESS(vme)
switches on the raw byte offset and names TEN offsets: 0x00, GCSRCTL 0x2c, TCR 0x4c,
T1CMP 0x50, T1COUNT 0x54, TCTL 0x60, IRQEN 0x6c, IRQL3 0x80, IRQL4 0x84, VBR 0x88.
Every other offset of the 4 KiB window reaches `default:', which prints with debug() and
calls exit(1): one guest load or store there ends the emulator, and free-running at default
verbosity it says nothing first (debug() returns early; fatal() would not).

THE RULED DISPOSITION, as the sketch implements it:
  population 2 -- the 26 register WORD STARTS the header names that have no case (the
      header's 36 contiguous words 0x00..0x8c minus the ten): DECLINE + ANNOUNCE ONCE.
      Exact word-start labels; a read serves d->reg[w] (0: nothing writes those words); a
      write is dropped; one latched fatal() per register per instance, `(once)' marker.
  population 1 -- the 988 unnamed word starts 0x90..0xffc, and every offset that is not
      one of the 36 exact labels: FAULT.  `default:' keeps its two debug() lines and
      returns 0; memory_rw.c turns that into the m88k data-access exception (vector 3;
      VBR is 0 at reset, so PC 0x18), recording DMT0/DMD0/DMA0.

RUNG 3: real MC88100 instructions through real address decode and real memory_rw on the
UNMODIFIED in-tree `-E mvme88k -e mvme187', which already attaches the device
(machine_mvme88k.c: "vme addr=0x%x", VME2_BASE = 0xfff40000).  Stepped sessions feed the
debugger on stdin (mk48_nvram_probe.py's shape); FREE-RUNNING sessions drive it through a
pty, one command at a time, and send nothing while the guest runs -- the debugger reads
MAIN_CONSOLE, so a queued line could reach the guest's console instead
(pcc2_width_probe.py's shape).  Only a free-running session can tell fatal() from
debug(): stepping makes both print.

EXCEPTION MECHANICS this probe relies on (src/cpus/cpu_m88k.c, m88k_exception):
  * a data-access exception sets PSR.SFRZ; a SECOND one while SFRZ is set is rerouted to
    ERROR -- so every stepped fault row has a session of its own;
  * the destination register of a faulting load is NOT written, so a row seeds it with a
    sentinel and the sentinel must survive;
  * the vector word at 0x18 is `br' to itself: an all-zero word there is `goto bad' --
    measured: "cpu: UNIMPLEMENTED instruction at 0x18", "emul: All machines stopped"
    (explore2_FIX.out) -- which is what left the 2026-10-09 measurement's PC at 0x18;
  * `rte' restores PSR from EPSR (SFRZ clear) and resumes at SNIP = faulting PC + 4, so a
    two-instruction handler (addu r1,r1,1 ; rte) COUNTS faults in one free-running
    session -- that is how `p1 census' covers all 988 words.

ENCODINGS are hand-assembled (op26 per cpu_m88k_instr.c's decoder: ld.hu 0x02, ld.bu 0x03,
ld.d 0x04, ld 0x05, st 0x09, or 0x16, addu 0x18, br 0x30 with d26 = 0, rte 0xf400fc00).
EVERY placed word is re-read with the debugger's `unassemble' and compared word, mnemonic
and operands against an expectation written here independently (row `unasm', count pinned
by a LITERAL).  The rows that expect 0 have companions that expect a NONZERO value through
the same base register: `vbr reset' (0x67000000), `t1cmp rt', `cased census' (VBR and
T1COUNT's +100), and every population-2 session opens with its own VBR read.

ROWS -- the mutant each is aimed at, and the observable that differs under it (CHANNEL).
*** EVERY MUTANT OUTCOME IN THIS LIST IS PREDICTED BY READING THE SKETCH.  No mutant was built
for this draft (2026-10-20); only HEAD, the sketch and the null medium were measured
(run_HEAD.out / run_FIX.out / run_NULL.out).  The kill table owes each prediction. ***
  session / live / unasm / neg apparatus   apparatus: rc; an or-immediate; the disassembler
        cross-check; a bogus subtype MUST red the liveness oracle (it is failable)
  vbr reset      DEVICE SIGNATURE: DEVINIT's VBR seed.  RAM, or a build without the device,
                 answers 0 (measured: run_NULL.out)
  t1cmp rt       the accept side of the edited switch: a word stored at cased T1CMP reads back
  cased census   one ld at each of the ten cased offsets in ONE session, a second T1COUNT read
                 (+100) and a liveness or: a cased label dropped -> that offset FAULTs (PC
                 0x18) and every later load keeps its sentinel
  free ctl       FREE-RUNNING shape control on cased T1CMP: breakpoint reached, word round-trips
  free quiet     ...and that run prints NO vme text: a cased access announces nothing
  p2 rd census   26 ld, one per population-2 register, ONE session: any label dropped ->
                 FAULT (PC 0x18, later registers keep the sentinel); HEAD -> host dies
  p2 wr census   26 st of 0xa5a5a5a5 then the 26 ld: a decline that STORES (backed accept)
                 reads back 0xa5a5a5a5 -- visible only because the arm does NOT force
                 odata = 0; a decline conditioned on direction FAULTs the first store
  p2 width       ld.bu + ld.hu at 0x28, ld.d at 0x08: a decline conditioned on len == 4
                 FAULTs the narrower / wider form
  p2 announce    FREE-RUNNING, the 26 reads: lines/distinct-population-2-offsets named,
                 want 26/26; a latch shared per device gives 1/1; fatal -> debug gives 0/0
  p2 once        the same 26 reads again in the SAME session: 0 new lines; a latch never set
                 gives 26.  Graded only when pass 1 announced, so 0 cannot be vacuous
  p2 wr announce [ADDED beyond the brief's section 6] FREE-RUNNING, 26 writes then the 26
                 reads: want 26 write lines naming the 26 offsets and 0 read lines.  The
                 sketch has TWO fatal() calls; section 6's `fatal -> debug' applied to the
                 WRITE one left every section-6 row green (p2 announce reads only).  A
                 per-direction latch gives 26/26/26; a write announce dropped gives 0/0/26.
                 Kills PREDICTED here, not measured
  p1 fault lo/hi ld at 0x90 / 0xffc: PC 0x18, DMA0 = the address, host alive.  `return 0'
                 -> `break' serves the read (PC advances); exit(1) reinstated kills the host
  p1 fault wr    st at 0x90: PC 0x18 and the DMT0 WRITE form 0x403f
  p1 p2 edge     ld 0x8c then ld 0x90: 0x8c declines (0), 0x90 faults.  MISC's label
                 dropped faults at 0x8c instead (DMA0 0xfff4008c); a label added AT 0x90
                 declines it.  A label added at any OTHER population-1 word is p1 census's
  p3 interim     ld.bu at 0x51, inside cased T1CMP: FAULT -- 7n-4's interim pin, NAMED as
                 vmewidthlanes' channel: that round reds this row and re-derives it
  p1 census      [ADDED beyond the brief's section 6] FREE-RUNNING, all 988 population-1 word
                 starts, faults counted by the handler: a label added at ANY population-1
                 word declines it (987); `return 0' -> `break' gives 0; exit(1) kills.  Its
                 kill of the added-label mutant is PREDICTED here, not measured

CONTRACT (clause e) -- what this instrument is designed to catch is the CHANNEL list above.
NOT CLAIMED, stated so a later escape is outside the contract rather than an argument:
  * populations 3 and 4 (sub-word starts inside cased words; a cased base at len != 4):
    filed as vmewidthlanes; `p3 interim' pins ONE population-3 cell as that round's channel;
  * sub-word starts inside POPULATION-2 words (e.g. a byte at 0x29): under exact labels they
    FAULT; no scored row (an INFO line reports it);
  * population-2 widths other than ld.bu/ld.hu at 0x28 and ld.d at 0x08; any narrow or
    doubleword STORE; population-1 writes other than 0x90; population-1 narrow/doubleword
    accesses other than p3's byte;
  * ld.d / st.d spanning two registers: an 8-byte access at a population-2 base is served as
    ONE word zero-extended and sets ONE latch bit; nothing here pins which;
  * the announce text beyond its marker, its direction and the offset it names -- `(len %d)'
    and the written value are unpinned; announces are counted only for WORD accesses;
  * per-instance versus process-global latch storage: mvme187 attaches ONE vme device;
  * what a guest OS does with the declined values (OpenBSD's abort handler reads IRQSTAT 0);
  * anything about the real VMEchip2 (its register chapter is not on disk).

TEST-FIRST SHAPE: on the committed HEAD every session touching population 1 or 2 ends the
host (exit 1), so those rows red; the controls stay green.

Sentinel: VME_DEFAULT_PROBE_DONE (plus VME_DEFAULT_RESULT=n/N, VME_DEFAULT_CONTROL=OK|FAIL)
"""

import pty
import re
import select
import shutil

import sys
import tempfile
import time

if len(sys.argv) < 2:
    sys.stderr.write("usage: vme_default_probe.py <gxemul> [label]\n")
    sys.exit(2)

BIN = sys.argv[1]
LABEL = sys.argv[2] if len(sys.argv) > 2 else "local"
#  A private dummy file: a shared /tmp path once let two concurrent runs race on it.
_TMPDIR = tempfile.mkdtemp(prefix="vme_default_")
DUMMY = os.path.join(_TMPDIR, "dummy.bin")
with open(DUMMY, "wb") as _f:
    _f.write(b"\x00\x00\x00\x00")

VME = 0xfff40000            # VME2_BASE (mvme88k_vme.h)
CODE = 0x00010000
CODE2 = 0x00010200          # the second pass of the two-pass free-running session
CENSUS = 0x00020000         # the population-1 census program
VEC_DACC = 0x18             # VBR 0 + 8 * M88K_EXCEPTION_DATA_ACCESS (3)
VEC_MISAL = 0x20            # VBR 0 + 8 * M88K_EXCEPTION_MISALIGNED_ACCESS (4)
SENT = 0xdeadbeef
WVAL = 0xa5a5a5a5
T1VAL = 0x12345678
VBR_SEED = 0x67000000       # DEVINIT: VME2_SET_VBR0(6) + VME2_SET_VBR1(7) = 6 << 28 | 7 << 24
LIVE = 0x1234
T1COUNT_STEP = 100          # the T1COUNT read arm's `+= 100' (after the preload has served)

#  DMT0 for a word store, as cpu_m88k_instr_loadstore.c composes it (m88k_dmt.h): VALID 0x1,
#  WRITE 0x2, DAS 0x4000 (supervisor), all four byte enables 0xf << 2 -- 0x403f.  (A load
#  carries DREG << 7 instead of WRITE; no row asserts the load form.)
DMT_WORD_STORE = 0x1 | 0x2 | 0x4000 | (0xf << 2)

CASED = (0x00, 0x2c, 0x4c, 0x50, 0x54, 0x60, 0x6c, 0x80, 0x84, 0x88)
POP2 = ((0x04, "SADDR2"), (0x08, "SLAVELMOD1"), (0x0c, "SLAVELMOD2"), (0x10, "SLAVECTL"),
        (0x14, "MASTER1"), (0x18, "MASTER2"), (0x1c, "MASTER3"), (0x20, "MASTER4"),
        (0x24, "MASTER4MOD"), (0x28, "MASTERCTL"), (0x30, "DMACTL"), (0x34, "DMAMODE"),
        (0x38, "DMALADDR"), (0x3c, "DMAVMEADDR"), (0x40, "DMACOUNT"), (0x44, "DMATABLE"),
        (0x48, "DMASTAT"), (0x58, "T2CMP"), (0x5c, "T2COUNT"), (0x64, "PRESCALE"),
        (0x68, "IRQSTAT"), (0x70, "SETSOFTIRQ"), (0x74, "IRQCLR"), (0x78, "IRQL1"),
        (0x7c, "IRQL2"), (0x8c, "MISC"))
POP2_OFFS = tuple(o for o, _ in POP2)
POP1 = tuple(range(0x90, 0x1000, 4))
#  The header's register block is 36 CONTIGUOUS words, 0x00..0x8c: cased + population 2 must

assert len(CASED) == 10 and len(POP2) == 26 and len(POP1) == 988
assert sorted(CASED + POP2_OFFS) == list(range(0, 0x90, 4))

PROMPT = "GXemul> "
ANN_RE = re.compile(r"\[ vme: unimplemented (read from|write to) register (0x[0-9a-f]+) "
                    r"\(len (\d+)\)[^\n]*\(once\) \]")
VMETXT_RE = re.compile(r"\[ vme:")


# ------------------------------------------------------------------- encodings
class Ins(object):
    __slots__ = ("word", "mnem", "ops")

    def __init__(self, word, mnem, ops):
        self.word, self.mnem, self.ops = word, mnem, ops


def enc(op26, rd, rs1, imm):
    assert 0 <= op26 < 64 and 0 <= rd < 32 and 0 <= rs1 < 32 and 0 <= imm <= 0xffff
    return (op26 << 26) | (rd << 21) | (rs1 << 16) | imm


def _mem(op26, mnem, rd, off, rs1):
    return Ins(enc(op26, rd, rs1, off), mnem, "r%d,r%d,0x%x" % (rd, rs1, off))


def LD(rd, off, rs1=3):
    return _mem(0x05, "ld", rd, off, rs1)


def LD_BU(rd, off, rs1=3):
    return _mem(0x03, "ld.bu", rd, off, rs1)


def LD_HU(rd, off, rs1=3):
    return _mem(0x02, "ld.hu", rd, off, rs1)


def LD_D(rd, off, rs1=3):
    assert rd != 31
    return _mem(0x04, "ld.d", rd, off, rs1)


def ST(rs, off, rs1=3):
    return _mem(0x09, "st", rs, off, rs1)


def OR_I(rd, rs1, imm):
    assert rd != 0
    return Ins(enc(0x16, rd, rs1, imm), "or", "r%d,r%d,0x%x" % (rd, rs1, imm))


def ADDU_I(rd, rs1, imm):
    #  the disassembler prints this immediate in DECIMAL (cpu_m88k.c: "%s\tr%i,r%i,%i")
    return Ins(enc(0x18, rd, rs1, imm), "addu", "r%d,r%d,%d" % (rd, rs1, imm))


def RTE():
    return Ins(0xf400fc00, "rte", "")


def BR_SELF():
    #  op26 0x30, d26 = 0: the target is the branch itself; the operand is filled in on placement
    return Ins(0xc0000000, "br", None)


# ------------------------------------------------------------------- sessions
def hx(v):
    return "absent" if v is None else "0x%x" % v


def argv_for(subtype):
    return [BIN, "-V", "-x", "-E", "mvme88k", "-e", subtype, "-M", "64",
            "0x%x:%s" % (CODE, DUMMY)]


def seeds(pairs):
    return ["r%d=0x%x" % (r, v) for r, v in pairs]


def place(blocks):
    """blocks: [(addr, [Ins])] -> (debugger commands, [(addr, Ins)]).  Every block is
       re-read with `unassemble' (end-exclusive) right after it is written."""
    cmds, placed = [], []
    for at, insns in blocks:
        for i, ins in enumerate(insns):
            a = at + 4 * i
            if ins.ops is None:
                ins = Ins(ins.word, ins.mnem, "0x%08x" % a)
            cmds.append("put w 0x%x, 0x%08x" % (a, ins.word))
            placed.append((a, ins))
        cmds.append("unassemble 0x%x 0x%x" % (at, at + 4 * len(insns)))
    return cmds, placed


def run_piped(cmds, subtype="mvme187", timeout=90):
    inp = ("\n".join(list(cmds) + ["quit"]) + "\n").encode("latin-1")
    try:
        p = subprocess.run(argv_for(subtype), input=inp, stdout=subprocess.PIPE,
                           stderr=subprocess.STDOUT, timeout=timeout)
    except subprocess.TimeoutExpired as e:
        return (e.output or b"").decode("latin-1", "replace").replace("\r", ""), "TIMEOUT"
    rc = p.returncode
    return (p.stdout.decode("latin-1", "replace").replace("\r", ""),
            ("sig%d" % -rc) if rc < 0 else ("exit%d" % rc))


def run_pty(cmds, t_cmd=10.0, t_run=30.0):
    """One command at a time through a pty.  An ordinary command waits for the next
       prompt; `continue' waits for BREAKPOINT and then a prompt after it, and nothing is
       sent while the guest runs.  -> (transcript, how); how is exitN / sigN, or
       no-prompt / no-breakpoint (the child is then killed: a guest still running would
       never read `quit')."""
    pid, fd = pty.fork()
    if pid == 0:
        try:
            os.execv(BIN, argv_for("mvme187"))
        finally:
            os._exit(127)
    buf = [""]

    def pump(deadline, pred):
        while True:
            if pred():
                return "ok"
            left = deadline - time.time()
            if left <= 0:
                return "timeout"
            r, _, _ = select.select([fd], [], [], min(left, 0.05))
            if not r:
                continue
            try:
                d = os.read(fd, 65536)
            except OSError:
                return "eof"
            if not d:
                return "eof"
            buf[0] += d.decode("latin-1", "replace")

    state = pump(time.time() + 20.0, lambda: PROMPT in buf[0])
    failed = None if state == "ok" else ("no-prompt" if state == "timeout" else None)
    if state == "ok":
        for c in cmds:
            start = len(buf[0])
            try:
                os.write(fd, (c + "\n").encode("latin-1"))
            except OSError:
                state = "eof"
                break
            if c == "continue":
                def pred(start=start):
                    b = buf[0].find("BREAKPOINT", start)
                    return b >= 0 and buf[0].find(PROMPT, b) >= 0
                state = pump(time.time() + t_run, pred)
                if state == "timeout":
                    failed = "no-breakpoint"
            else:
                state = pump(time.time() + t_cmd,
                             lambda start=start: buf[0].find(PROMPT, start) >= 0)
                if state == "timeout":
                    failed = "no-prompt"
            if state != "ok":
                break
    if state == "ok":
        try:
            os.write(fd, b"quit\n")
        except OSError:
            pass
        pump(time.time() + 5.0, lambda: False)
    try:
        os.close(fd)
    except OSError:
        pass
    stat, reaped = None, False
    for attempt in range(2):
        for _ in range(40):
            try:
                p, s = os.waitpid(pid, os.WNOHANG)
            except OSError:
                p, s = pid, None
            if p:
                stat, reaped = s, True
                break
            time.sleep(0.05)
        if reaped:
            break
        try:
            os.kill(pid, 9)
        except OSError:
            pass
        failed = failed or "killed"
    if failed:
        how = failed
    elif stat is None:
        how = "unreaped"
    elif os.WIFSIGNALED(stat):
        how = "sig%d" % os.WTERMSIG(stat)
    else:
        how = "exit%d" % os.WEXITSTATUS(stat)
    return buf[0].replace("\r", ""), how


DIS_RE = re.compile(r"^[su]([0-9a-f]{8}): ([0-9a-f]{8})\s+(?:<-\s+)?(\S+)(?:\t(\S+))?[ \t]*$", re.M)
GPR_RE = re.compile(r"\br(\d+)\s*=\s*(0x[0-9a-fA-F]+)")
PC_RE = re.compile(r"cpu\d+:\s+pc\s+=\s+(0x[0-9a-fA-F]+)")
CR_RE = re.compile(r"\b([A-Z][A-Z0-9]*)=(0x[0-9a-fA-F]+)")


class Res(object):
    pass


def analyse(text, how, placed):
    """Split the transcript at the prompts; parse every unassemble, every reg dump (in
       order) and the last `reg 0,0'."""
    r = Res()
    r.how, r.text, r.placed = how, text, placed
    r.dis, r.dumps, r.cr, r.conts = {}, [], None, []
    for part in text.split(PROMPT)[1:]:
        cmd, _, out = part.partition("\n")
        cmd = cmd.strip()
        if cmd.startswith("unassemble"):
            for m in DIS_RE.finditer(out):
                r.dis[int(m.group(1), 16)] = (int(m.group(2), 16), m.group(3), m.group(4) or "")
        elif cmd == "reg":
            m = PC_RE.search(out)
            if m:
                r.dumps.append(({int(g.group(1)): int(g.group(2), 16)
                                 for g in GPR_RE.finditer(out)}, int(m.group(1), 16)))
        elif cmd == "reg 0,0":
            cr = {g.group(1): int(g.group(2), 16) for g in CR_RE.finditer(out)}
            if cr:
                r.cr = cr
        elif cmd == "continue":
            r.conts.append(out)
    r.regs, r.pc = r.dumps[-1] if r.dumps else (None, None)
    return r


UNASM = {"ok": 0, "n": 0, "bad": []}


def check_unasm(r, scored=True):
    ok = n = 0
    for a, ins in r.placed:
        n += 1
        d = r.dis.get(a)
        if d is not None and d == (ins.word, ins.mnem, ins.ops):
            ok += 1
        elif scored:
            UNASM["bad"].append("0x%x:%08x %s %s -> %r" % (a, ins.word, ins.mnem, ins.ops, d))
    if scored:
        UNASM["ok"] += ok
        UNASM["n"] += n
    return ok, n


def stepped(blocks, regs, nsteps, cr=False, scored=True):
    cmds, placed = place(blocks)
    cmds = seeds(regs) + cmds + ["pc=0x%x" % CODE, "step %d" % nsteps, "reg"]
    if cr:
        cmds.append("reg 0,0")
    t, how = run_piped(cmds)
    r = analyse(t, how, placed)
    check_unasm(r, scored)
    return r


def freerun(blocks, regs, bps, runs):
    """runs: [start pc] -- each is `pc=<start>', `continue', `reg'.  All code, every
       unassemble and every breakpoint go in BEFORE the first `continue', so the disassembly
       cross-check never depends on surviving a run."""
    cmds, placed = place(blocks)
    cmds = seeds(regs) + cmds + ["breakpoint add 0x%x" % b for b in bps]
    for start in runs:
        cmds += ["pc=0x%x" % start, "continue", "reg"]
    t, how = run_pty(cmds)
    r = analyse(t, how, placed)
    check_unasm(r)
    return r


def died(r):
    return "died:%s" % r.how


def reg(r, n):
    if r.regs is None:
        return died(r) if r.how != "exit0" else "absent"
    return hx(r.regs.get(n))


def devsig_bad(r):
    """None when the session's own opening VBR read saw the device; else the reason."""
    if r.regs is None:
        return died(r)
    if r.regs.get(30) != VBR_SEED:
        return "nodev r30=%s (FAILED FOR SOME OTHER REASON)" % hx(r.regs.get(30))
    return None


rows = []


def row(name, got, want, note=""):
    assert name not in [n for n, _ in rows], "DUPLICATE ROW NAME %r" % name
    assert len(name) <= 15, name     # `%-16s ' keeps a gate's `^$v  .*ok$' satisfiable
    ok = (got == want)
    rows.append((name, ok))
    print("%-16s %-30s %-30s %-58s %s" % (name, str(got), str(want), note,
                                          "ok" if ok else "FAIL"))
    sys.stdout.flush()
    return ok

def fault_row(name, access, extra_seeds, field, want, note):
    prog = [LD(30, 0x88), access, OR_I(5, 0, LIVE), BR_SELF()]
    r = stepped([(VEC_DACC, [BR_SELF()]), (CODE, prog)],
                [(3, VME), (4, SENT), (5, SENT), (30, SENT)] + extra_seeds, 3, cr=True)
    bad = devsig_bad(r)
    if bad:
        got = bad
    else:
        got = "%s/%s/%s" % (r.how, hx(r.pc), hx((r.cr or {}).get(field)))
        #  a faulting load writes no register, and the instruction after it never runs
        for rr in (4, 5):
            if r.regs.get(rr) != SENT:
                got += " r%d=%s" % (rr, hx(r.regs.get(rr)))
    row(name, got, want, note)
