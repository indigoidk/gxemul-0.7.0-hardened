**Row that should catch it and cannot:** a count row on the sh08b session, e.g. `said(t, 2, 0x08, clean) == 1` (or `count(t, "-- declined.", clean) == 1`). It does not exist. ## 2. Conditional second gap — a premise the packet cannot settle

READ: the CONTROL arm tests a **third** bit besides DOG and RESET — `idata &= ~CRIME_CONTROL_ENDIANESS` — and clause 3 claims "the arm's TESTED idata bits both ways at 2W", while the POSTTABLE denominator says only "the arm's tested **DOG and RESET** bits both ways at 2W". READ (internal evidence): bit 0 is not ENDIANESS — `sw08 msg ctl` ("sw 0x01 prints the text") is a base-passing control, and `~ENDIANESS` would have eaten bit 0.

**NOT CHECKABLE from the packet: the numeric value of `CRIME_CONTROL_ENDIANESS`.** One grep settles it. If it is any bit a halfword can carry other than 0x200/0x800, then this also scores 85/85:

`goto crime_declined;` → `if (!(relative_addr == CRIME_CONTROL && len == 2 && writeflag == MEM_WRITE && (idata & CRIME_CONTROL_ENDIANESS))) goto crime_declined;`

— a refused `sh` of E|HARD_RESET then stops every CPU (the exact harm the goto exists to prevent), and no rowed refused store carries E (sh 0x0800/0x0201/0x0a00 write only bits {0,9,11}; READ). That is c_dog's class at a bit the arm explicitly tests. If E is 0 or ≥ 0x10000, no gap (no-op/unreachable at widths 1–2).

Same family, unconditional (REASONED): bits 1–8, 10, 12–15 are never written set by any refused 2W at CONTROL, so a fall-through keyed on `idata & 0x0002` at that cell escapes too (a guest `sh 0x0802` stops every CPU). Whether that is floor or clause-(e) debt turns on "TESTED": the residue test `if (idata != 0)` does distinguish those bits, and the header does not say.
