### 1. The fix

The declined path does what the comment says.

Inside the `else` (`len` is neither 8 nor 4): latch bit 0, print once, `goto crime_declined`. That skips the `switch`. `odata` is still 0 from the function entry, so the tail’s `memory_writemax64` answers a read 0. A write was assembled into `idata` at the top and is never stored. The function `return 1`s, so `memory_rw.c:595-612` does not coerce that to `-1` and does not raise `EXCEPTION_DBE`. `fatal()` in `debugmsg.c:384-390` has no early-out and no `exit`.

`#498` `DEVICE_ACCESS(sgi_de)` is the same shape: latched `(once)` + `goto de_declined` to a tail that writes `odata` and returns 1 (`dev_sgi_re.c:1214-1219`, label at `:1438`). Crime’s tail also restores HARDINT and recomputes INTSTAT; that is this function’s pre-existing common exit, not an invention.

**Prelude.** It still runs for a declined access. Two live `exit(1)`s remain (`physical_ram_in_mb > 1024` and the `% mb_per_bank` check). Those are the filed `-M 48` item, above the width arm, and the probe uses `-M 64`. The REV / CONTROL / INTSTAT / bank-control rebuilds are pre-existing on every access, including accepted ones; decline does not make them worse. A declined write to DOG is dropped (prelude does not touch DOG). A declined write to CONTROL still leaves CONTROL at `CRIME_CONTROL_ENDIANESS` because the prelude wrote it — the same smash an accepted read of any other register already performs.

**Latch.** `int warned` + `CRIME_W_LEN` `(1 << 0)` + `(once)` + `memset(d, 0, sizeof *d)` at `dev_crime_init` is the house N=1 per-instance form. `#498` uses `uint32_t warned`; `int` is enough for bit 0. Writers of `d->warned` in this file are only the test, the `|=`, and that `memset`. MACE has no `warned`.

`goto` vs `return 1` is equivalent on this detector (`probe_return1.raw` 40/40). `memory_rw.c:491-492` does `#95`’s `memset(data, 0, len)` immediately above `paddr -= mem->devices[i].baseaddr`. I did not find a declined-path channel where skipping the HARDINT restore would show; prelude never writes HARDINT, and the decline never takes the width-arm store.
