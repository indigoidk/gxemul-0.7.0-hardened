The MTE cases can reuse the IP32 session machinery, but I found no targeted coverage for their transfer guards in the permitted top-level Python files. Their new coverage must establish command refusal, continued execution, latch behavior and a supported-command control.

TEX costs more because its [write indexing](C:/DocumentNoSnc/CC/GXEMUL/GXEMUL-SEC/src/devices/dev_sgi_re.c:486) advances the starting index by one halfword per eight-byte slot, while each write stores four halfwords.
