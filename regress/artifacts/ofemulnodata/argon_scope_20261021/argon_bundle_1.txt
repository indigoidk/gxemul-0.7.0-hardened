==== FILE R = the option-set and round-scope rules ====
R:O1 (the option set).  "1 DELETE . 2 DECLINE (silent) . 3 DECLINE + BOUNDED (LATCHED) ANNOUNCE . 4 ACCEPT . 5 FAULT .
R:6 BACKED ACCEPT . 7 IMPLEMENT".  4 ACCEPT: the model already computes the right value -- delete the kill, keep the value,
R:no latch.  5 FAULT: deliver the architectural error.  7 IMPLEMENT: "All six members above presume the access is a REFUSAL
R:DECISION, and that presumption fails for an UNIMPLEMENTED PATH ... The tell that member 7 is the right one is a site with
R:NO PREDICATE."
R:O2 (availability).  "BEFORE CHOOSING A MEMBER, CHECK IT IS AVAILABLE ON THIS CPU.  The set is a menu of dispositions, not a
R:menu of things every machine can do."
R:O3 (the house latch).  A guest-drivable fatal() needs a LATCH, not a verbosity flag: "N = 1, PER DEVICE INSTANCE, PLUS AN
R:EXPLICIT SUPPRESSION MARKER IN THE MESSAGE TEXT", `(once)` the usual spelling.  fatal() itself does not exit.
R:O4 (the addition licence).  "Additions to product code in a hardening fork are licensed by MEASURED DELTAS or by a
R:TRANSFERRED WARRANT -- never by 'it cannot hurt.'"
R:O5 (round scope).  "A round takes ONE site; a second joins only if it is witnessed, in the SAME device and SAME semantic
R:class ... (so one fix design covers both), and covered by the SAME detector with no new oracle.  More witnesses create
R:more candidate ROUNDS, never bigger rounds."
R:O6 (the sketch rule).  "A PROPOSED EDIT IS A SKETCH, NOT A FIX, UNTIL IT HAS BEEN RUN AGAINST THE ENCLOSING FUNCTION'S
R:REAL CONTROL FLOW" -- every exit path and the common tail.  Here the callers' tails matter: X(openfirmware) sets the pc
R:from the link register after of_emul returns.
R:O7 (de-escalation).  "When a fix removes a host-fatal guard, enumerate from the diff every predicate that used to gate
R:death, and the detector shipping with that fix must pin the ACCEPT SIDE of each" -- here, that macppc's OpenFirmware
R:calls still work.
