### 1. Verification of the Fix and Mechanics

* **The Fix Implementation:**
  In [`src/devices/dev_lca.c:295-312`](file:///C:/DocumentNoSnc/CC/GXEMUL/GXEMUL-SEC/src/devices/dev_lca.c#L295-L312):
  ```c
  if (len == 0)
      return 0;
  ofs = (relative_addr & 3) % len;

  if (writeflag == MEM_WRITE) {
      byte = data[ofs];
      return cpu->memory_rw(cpu, cpu->mem, LCA_ISA_BASE +
          relative_addr, &byte, 1, writeflag, CACHE_NONE);
  }

  cpu->memory_rw(cpu, cpu->mem, LCA_ISA_BASE + relative_addr,
      &byte, 1, MEM_READ, CACHE_NONE);

  for (i=0; i<len; i++)
      data[i] = i == ofs? byte : 0x00;

  return 1;
  ```
  * `len == 0` is guarded prior to the modulo operator (`% len`), eliminating potential host divide-by-zero.
  * `ofs = (relative_addr & 3) % len` correctly places the single target byte for port $P$ at buffer index $(P \pmod 4) \pmod{\text{len}}$ on both arms.
  * Write arm indexes `data[ofs]`.
  * Read arm places `byte` at `data[ofs]` and zeroes other bytes up to `len`.

* **1 KB Split Mechanics:**
  In [`src/cpus/memory_rw.c:186-224`](file:///C:/DocumentNoSnc/CC/GXEMUL/GXEMUL-SEC/src/cpus/memory_rw.c#L186-L224), [`MRW_SPLIT_MASK`](file:///C:/DocumentNoSnc/CC/GXEMUL/GXEMUL-SEC/src/cpus/memory_rw.c#L104) is `0x3ff` (1024-byte granule). On Alpha (where `cpu->translate_v2p != NULL`), non-`PHYSICAL` accesses crossing a 1024-byte boundary split into a `head = granule - offset` and a remainder `tail`.
  Because sparse LCA ISA addresses shift right by 5 bits (`relative_addr >>= 5` in [`src/devices/dev_lca.c:280`](file:///C:/DocumentNoSnc/CC/GXEMUL/GXEMUL-SEC/src/devices/dev_lca.c#L280)), each ISA port occupies $2^5 = 32$ bytes. A 1024-byte boundary in virtual address space maps to $1024 / 32 = 32$ ports ($0\text{x}20$).
  Consequently:
  * Every split **HEAD** ends at port offset $0\text{x}3\text{ff} \pmod{0\text{x}400}$, which is port $31 = 0\text{x}1\text{f} \pmod{0\text{x}20}$. Since $31 \pmod 4 = 3$, every split head lands on **lane 3**.
  * Every split **TAIL** begins at port offset $0\text{x}000 \pmod{0\text{x}400}$, which is port $0 \pmod{0\text{x}20}$, landing on **lane 0**.
  * If a head chunk fails, [`MEMORY_RW`](file:///C:/DocumentNoSnc/CC/GXEMUL/GXEMUL-SEC/src/cpus/memory_rw.c#L183) returns [`MEMORY_ACCESS_FAILED`](file:///C:/DocumentNoSnc/CC/GXEMUL/GXEMUL-SEC/src/cpus/memory_rw.c#L216) immediately before issuing the tail chunk.
