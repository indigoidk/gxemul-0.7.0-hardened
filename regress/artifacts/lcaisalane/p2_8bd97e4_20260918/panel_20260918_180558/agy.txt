#### Q2 -- Governing Rule, Floor Adjudication, Class Closure, and L4 Audit

1. **Governing Rule: Joint-Cells Letter vs. Pass 6 Criterion**
   - **The 2026-09-04 Joint-Cells letter governs**: *"DEPENDS-ON enumerates JOINT cells over the guard's operands and the body-read lvalues EXACTLY WHEN THE GUARDED BODY'S OWN CODE DISTINGUISHES THEM. ... A value or combination the body never tests as a case is DISCLOSED under clause (e)."*
   - **Why Pass 6's criterion does not govern**: Pass 6 ruled `len <= 8` as L2 because the *entire* instruction-driven test suite could not emit $\text{len} > 8$ for a guest-reachable path. Treating any divergence "outside the probed set" as an L2 floor breach would create an infinite regress: any finite detector can be evaded by a synthetic mutant conditioned on the probe's exact arguments (e.g. `len <= 16`, `port == 0x2ff`). The Joint-Cells rule exists specifically to bound DEPENDS-ON to partitions induced by the product code under repair.
   - Since [`dev_lca.c:275-312`](file:///C:/DocumentNoSnc/CC/GXEMUL/GXEMUL-SEC/src/devices/dev_lca.c#L275-L312) only tests `len == 0` and `writeflag == MEM_WRITE`, constants like `16`, `64`, `0x200`, and `0x10` introduce partitions never induced by the body. They are **clause-(e) disclosures**, not L2 floor breaches.
   - **Result**: ZERO L2 floor breaches.

2. **Audit of Section 4 Arithmetic (The 12 Reachable Wide Cells)**
   - Section 4 claims 12 reachable wide cells emitted by `store_buf` ($A = 32P + k$ with $0 \le k < 32$):
     - $C = 16$: Condition $(32P + k) \pmod{16} == 0 \implies k \in \{0, 16\}$ for any $P$. $P \pmod 4 \in \{0, 1, 2, 3\}$. Total $2 \times 4 = 8$ cells.
     - $C = 64$: Condition $(32P + k) \pmod{64} == 0$. If $P$ is even, $k = 0$. If $P$ is odd, $32 + k = 64 \implies k = 32$, which is impossible since $k \in [0, 31]$. Hence $P$ must be even ($P \pmod 4 \in \{0, 2\}$) and $k = 0$. Total $1 \times 2 = 2$ cells.
     - $C = 256$: Condition $(32P + k) \pmod{256} == 0 \implies k = 0, P \equiv 0 \pmod 8 \implies P \pmod 4 = 0$. Total $1 \times 1 = 1$ cell.
     - $C = 1024$: Condition $(32P + k) \pmod{1024} == 0 \implies k = 0, P \equiv 0 \pmod{32} \implies P \pmod 4 = 0$. Total $1 \times 1 = 1$ cell.
     - **Verification**: Exactly 12 cells. The brief's arithmetic is 100% correct.

3. **Identification of L4 Wrong Records**
