**Q2 — which rule governs**

I apply the **joint-cells letter, read through observable distinction** — "the body's own code distinguishes them" must mean *the shipped code's guest-observable behavior varies over the partition*, not "the body contains an `if` testing it". Consequences:

- **pass 6's "diverges only outside the probed set ⇒ L2" does not govern as a general rule.** It keys breach-ness to an accident of the probe's domain, and if applied uniformly it empties clause (e): *every* disclosed cell is by definition "outside the probed set," so disclosure could never discharge anything. Clause (e) was textually adopted; it must carve a real exception. (Pass 6's *disposition* was still fine — the row it demanded was cheap and, per below, the width space turned out to contain real joint cells.)
- **A purely textual reading of the letter ("len is tested only against 0") is equally wrong in the other direction.** The write arm reads `data[ofs]` and forwards to `LCA_ISA_BASE + relative_addr`; which string byte is forwarded and which device register receives it are observable behaviors that vary with **lane** and with **port**, without any comparison. Those partitions are body-induced by *use*, so cells conditioned on lane or port are JOINT cells and clause (e) does not reach them.

Under that rule:
- **(c) is L2.** Lanes are body-distinguished (lane selects the forwarded byte *and* the low address bits). C=16/k=0/lanes 0–2 are reachable (a3=16, a2 at SP(0x2f8+…), e.g. MCR at 0x2fc or IER at 0x2f9 for read-back). No shipped row diverges there. — and note this is L2 **even under pass 6's criterion**, so the rule conflict does not rescue closure.
- **(e) is L2 on the cell question** (port identity is body-distinguished via the forward address; C=16 at P<0x200 is reachable input). Whether a distinguishing *row* is buildable needs a fact not in the packet — see P2 below.
- **(a), (b), (g) are clause-(e) debt under this rule** (len-magnitude and k are never observably distinguished by the body — k is erased by `>>= 5` before any read); they would be L2 under pass 6's criterion. Since (c)/(e) trigger the L2 branch anyway, I recommend the closure diff row the cells that kill them (below), upgrading debt to kills where the row is one line.

**L2 branch taken: class closure.** Is the 12-cell table the right space? — Mostly, with named edges:
