### 1. Premise audit

- **#505 `sgirergbroundtrip`**  
  **READ:** The diff changes the RGB GET arm from `buf[1..3]` to `buf[0..2]`.  
  **NOT CHECKABLE:** The claim that the PUT arm writes channels at `buf[0..2]` with pad at `buf[3]` is not in the packet.  
  **REASONED:** If that PUT layout is true, the fix is correct. The old read was off by one byte; the new read aligns with the stated layout.  
  **UB note:** The correction still uses `buf[i] << 24` on a promoted `uint8_t`. For bytes ≥ 0x80 this is undefined behaviour. That UB was already present in the old code, so #505 does not introduce it, but the fix does not remove it. The off-by-one defect is repaired; the UB is a separate defect filed as `sgirebufshiftub`.

- **#506 `lcaconfwidth`**  
  **READ:** Both sites change `(int)idata` with `%x` to `(uint64_t)idata` with `PRIx64`.  
  **REASONED:** The guard `idata & ~1` operates on the full 64-bit value. Casting to `int` before printing could show a value the guard accepts (e.g. `0x100000000` → `0x0`). The fix is correct.  
  **NOT CHECKABLE:** Whether `PRIx64` is available via an include is not shown, but the comment says sibling arms already use it, so likely fine.

- **#507 `alphaswpctxptbr`**  
  **READ:** The diff changes the second assignment from `apcb_ptbr = new_flags` to `apcb_flags = new_flags`.  
  **NOT CHECKABLE:** The earlier assignment to `apcb_ptbr` (three lines up) is not in the packet.  
  **REASONED:** If that earlier assignment exists, the fix is correct: `apcb_ptbr` is assigned once, `apcb_flags` is assigned once, and the transposition is removed.

- **#508 `alphapfnoffset`**  
  **READ:** The diff adds `| (vaddr & ((1ULL << pageSizeShift) - 1))` to the shifted PFN.  
  **REASONED:** The shifted PFN has low bits clear, so `|` and `+` are equivalent. The mask extracts the within-page offset from `vaddr`. The fix is correct.  
  **READ:** The comment explicitly states that `flags` is still ignored, protection bits untested, and `return 2` still reports every walked page writable. That is a disclosed partial repair, not a hidden one.
