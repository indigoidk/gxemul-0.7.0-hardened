#!/usr/bin/env python3
"""mk_ititles_brief.py -- write the grok brief that asks the RULING seat for a queue title on every id-less NEW row
whose governing line carries none (Astra's amendment governs and gives an instruction, not a title).  The row list is
taken from IDLESS_FILING.tsv; nothing is typed by hand."""
import io
import os

D = "C:/DocumentNoSnc/CC/GXEMUL/GXEMUL-SEC/regress/artifacts/idless_20261002"
rows = [l.rstrip("\n").split("\t") for l in io.open(os.path.join(D, "IDLESS_FILING.tsv"), encoding="utf-8")][1:]
need = [r for r in rows if r[1] == "NEW" and r[7] != "quoted"]
BS = chr(92)
WD = "C:" + BS + "DocumentNoSnc" + BS + "CC" + BS + "GXEMUL"
ART = WD + BS + "GXEMUL-SEC" + BS + "regress" + BS + "artifacts" + BS + "idless_20261002"
head = """QUEUE TITLES for %(n)d id-less rows -- your own rulings, as GPT-6 Astra amended them

FIRST line of your answer: `VERDICT: <t> of %(n)d titles written, <d> amendments disputed`.
SECOND line: the token `GROK_ITITLES_ALIVE_1002`.  THIRD line: quote verbatim the first line of
`%(wd)s%(bs)s_scratchpad%(bs)sCHECKPOINT.md`.

**Context.**  You ruled the id-less entries of this project's bug queue (`OUTSTANDING_BUGS.md`) slice by slice
(`%(art)s%(bs)sgrok%(bs)sgrok_ruleidless_<slice>.txt`), and GPT-6 Astra confirmed, overturned or amended each ruling
(`%(art)s%(bs)saconf_<slice>%(bs)scodex_aconf_<slice>.txt`).  Both are assembled, verbatim, in
`%(art)s%(bs)sIDLESS_DISPOSITIONS.md`.  A new queue row needs a TITLE -- one sentence that states the defect or the owed
work, true of the source, no wider and no narrower than the governing disposition.  For the %(n)d rows below the
governing line is Astra's amendment, and it gives an instruction ("narrowed to ...", "retaining ...") or nothing, not a
title.  The main loop must not write these titles from a paraphrase: that is how a condition gets dropped.

**The tree.**  `%(wd)s%(bs)sGXEMUL-SEC` (git) at commit `7440e129`; the queue line numbers below are commit `db8b1a33`'s
(read the queue text with `git -C %(wd)s%(bs)sGXEMUL-SEC show db8b1a33:OUTSTANDING_BUGS.md`; if `git show` is refused to
you, say so and read the file on disk by its text, not by its line numbers).  Never read any other `src/` under the
project root; never `git status` or `git diff`.  Write nothing.

**For each row, ONE line:**
`<id> | TITLE: <one sentence, at most 200 characters, no line numbers> | SCOPE: AS AMENDED / DISPUTE: <what Astra's amendment gets wrong, with file:line> | <the lines you read, path:line>`
* Write the title for the row AS AMENDED unless a first-hand reading shows the amendment is wrong; then write the
  title you can stand behind and say DISPUTE with the lines.  Do not concede or hold by default -- read.
* Where the governing line names a condition (a CPU model, a mode bit, a host option, "latent behind ..."), the title
  carries it.  Where it says the row is an owed MEASUREMENT or an owed RECORD correction rather than a defect, the
  title says that.
* Two ids appear twice in the table (`qharmexalign`, `qhnetxlog`): each is ONE row; write one title covering both
  queue passages and say so.

Then: **(a)** any of these rows whose defect the queue ALREADY files under another id (name the id and the queue
line); **(b)** `DENOMINATOR: <s> rows read in the source, <t> titled from the dispositions text alone, of %(n)d`.

**The rows** (id | grade | slice | queue lines at db8b1a33 | the governing line, cut at 520 characters; the whole line
and your own ruling line are in IDLESS_DISPOSITIONS.md under the slice):
""" % {"n": len(need), "wd": WD, "bs": BS, "art": ART}
body = []
for i, r in enumerate(need, 1):
    g = r[9] if len(r[9]) <= 520 else r[9][:517] + "..."
    body.append("%d. `%s` | %s | slice %s | %s | %s" % (i, r[0], r[2], r[3], r[5], g))
p = os.path.join(D, "briefs", "grok_ititles.md")
io.open(p, "w", encoding="utf-8", newline="\n").write(head + "\n".join(body) + "\n")
print("wrote %s: %d rows, %d bytes" % (p, len(need), os.path.getsize(p)))
